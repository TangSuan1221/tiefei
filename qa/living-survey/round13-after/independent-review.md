# Round13 独立视觉复核

结论：**保留本轮重排，但只认可为局部改善，不作为视觉验收通过。** 判断仅来自 round13-before / round13-after 各四张 fixed/near、live/film 配对图；未阅读既有review，也未查看实现代码。没有预设after应更好。

| 对照 | 观察与判断 |
| --- | --- |
| fixed-live | 门内右侧中央原先一块独立的横向暗斑弱化/消失，主通路更连贯。门外左侧新增的深黑斑靠近门脚，比漂在通道中间更有位置依据，但仍像一块轮廓偏直的贴片，未能明确读成从设施产生的污迹。门牌、黑黄门边和地面引导线没有可见辨识损失。小幅改善。 |
| fixed-film | 改善最明确：before通道中段右侧那块醒目的浅黄矩形，以及更远处的小亮块，不再像独立发光方砖抢视线。after恢复了门口、左侧设备及通道纵深的主次关系。不是单纯变暗，误导性的几何亮块确实减少。 |
| near-live | 左前机械件下方的大块深色平面收拢到设施附近，管件与其落地范围的关联较before更紧，通道中央更少被零散斑块切开。但近左仍留硬直边和三角形黑面，像叠在地上的薄片；中段棕色横向大斑仍横跨地面，与具体泄漏源关系不明。局部改善，未解决材质可信度。 |
| near-film | before中段浅黄色小矩形消失，after中央地面更统一，左侧设备的金属圈、软管及前景管线仍可辨。没有看到新遮挡或设备轮廓丢失。左侧青光过曝仍然压掉表面细节，未因本轮改善；不能把污迹重排当成照明改善。 |

**可读性结论：未见关键设施、门牌或通路辨识明显退步。** fixed-film少了亮矩形后，局部地面少一处亮点，但没有损害方向判断，反而减少了把污迹误读成灯/地砖/交互物的风险。fixed-live新出现的门外左黑斑有轻微“地洞/实体障碍”的歧义，当前位于边侧，尚不足以否决本轮，但不应扩展到道路中央。

仍未解决的差距：

- 污迹边缘仍偏直、偏平，近景有硬三角/矩形切边，缺少沿设备底脚、接缝、管路形成的连续痕迹；“移到设施旁”只改善空间关系，尚未建立可看懂的成因。
- 走廊中段棕色大斑仍像横铺的材质块；地面总体像由几块较大色面拼接，近距离经不起细看。
- 墙面重复的深色骨架和相似锈纹、空长廊的规则感没有改变。远端信息依然很少；这些静态图不足以判断实际驾驶或目标发现表现。
- film近景左侧蓝白高光仍严重，设备受光侧细节损失；live与film的曝光差异仍大。本轮没有提供解决该问题的证据。

建议保留当前重排，不恢复原来的通道中部矩形斑。后续优先处理现有污迹的硬边和与设备接触处的过渡，不继续增加斑块数量。本结论仅是八张固定截图的独立比较，不证明商业写实、真实影片质量或全关视觉达标。
