# 第三关有限资源预算（本地诊断）

2026-10-24。实现来源：`abyssal-lab-layout.ts`唯一物品表；`run.ts`真实库存、消耗和物资使用；`tools/abyssal-resource-check.ts`以1/60秒驱动生产PodRun.frame。并非正式媒体通关。

五个维护箱：Q/L/C/P/R电池分别2/2/2/2/1，Q和C各1氧烛，Q/C/P各1滤芯。三支开局宁神剂箱保留。机械臂取回后箱子消失并存档，不可反复领取。电池每个补0.42，氧烛新增实际补600氧（1450封顶），滤芯补0.55。均须使用既有生命维持工位。

库存仍为14格，超量走既有打捞台；UI明确起步前整理。预算每次取箱后主动丢弃全部台面溢出，因此不靠溢出台面无限携带。五个新增箱均通过实际世界Raycaster+完整艇体安全停泊检测，机械臂射线距离2.82–2.95m，13项含原物品全部通过；详见framing.json。

主路采用1315m，真实推进耗时约1047秒（17.45分钟）；另有600秒读取/等待。对额外174m垂直运动、5次摄影（含一次重拍）、16次分析（11远程+5本地）、20次主动声纳、30次机械臂呼吸成本按生产电耗常量作分布预算，共额外1.495电。此部分是预算而非真实媒体操作证据。正常实时静候在当前生产生理规则下不等价于每秒耗氧，报告保留此限制。

结果（resource-budget.json）：
- 无补给箱：含以上任务成本于648m断电。
- 满电满氧+1随身电池：用6电池/1滤芯，余61.9%电、1063氧。
- 25%电满氧+1随身电池：用7电池/1滤芯，余28.5%电、1056氧。
- 25%电/500氧+1随身电池：用7电池/1氧烛/1滤芯，余28.4%电、704氧。

这不是任意零资源存档保证；至少必须能抵达Q维护箱。超额重拍、长时间持续主动声纳、错误加热、持续撞击仍有成本。未生成视频，不授予证据或绕过剧情门禁。
