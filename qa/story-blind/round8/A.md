# 第一关对白稿 A

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：坐标发你了，在导航台上。过气闸走维修湾那条缝——全队只有你的艇挤得进去。
- 万斯：主动声纳别关——不开，那条缝你看不见。慢点开，罗温。我盯着你的点。
- 罗温：这里让我不舒服。
- 万斯：你一向讨厌人多。现在下面一个人都没有，你倒不舒服了。
- 万斯：……说话，罗温。你说话我就知道你还在。
- 〔驶到A气闸〕
- 万斯：门就在你正前方。门边有新划痕。别看，慢慢靠。
- （身后，压力门的液压杆长长泄了一口气。）
- 万斯：你深度读数在跳，载波也在掉——罗温？说句话，随便说句——
- 罗温：我有点怕。
- 万斯：……罗温，慢慢来，我在——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：（录音，循环）……泵站七，艾里亚斯，修泵的。一个人，断桥对面。……听见请回。小声。
- 罗温：坚持住，我马上过来。
- （循环录音在第三遍中途断掉。一声吞咽。）
- 艾里亚斯：有人。……真的有人。
- 艾里亚斯：过不来，桥断了——你别过来。
- 艾里亚斯：……你在对面？我抬一下手指。就一下。看见了吗？
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：就这样。喉麦，每口气我都得咽回去。你艇灯是老式镇流器，别打灯——会嗡。
- （门后，金属刮擦声。两下，一停。）
- 艾里亚斯：两下一停。它找东西的时候就这么敲。那扇门三天前就鼓了。我穿着硬壳服，头盔转不了——要看身后，得整个人挪。
- 艾里亚斯：你艇上有外景机吧？开到桥头灯杆底下，那是旧机位，正对我这扇门。我头灯不响，就是快没电了。拿指缝漏一线——够你拍。洗出来，告诉我上面有什么。
- 〔玩家在01曝光，显影，分析：门缝下沿探出三根细长的东西，停在艾里亚斯左脚跟后一掌。画面人物：艾里亚斯从栏杆上抬起两根手指，朝黑暗中的潜艇极轻地示意。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：别怕，什么都没有。
- 艾里亚斯：没什么？那门后面是什么在刮？
- 艾里亚斯：……算了。
- （静。）
- 艾里亚斯：门后是井。通港池。
- （静。）
- 艾里亚斯：走廊口在井盖正上面。它不挪，我过不去。
- （静。）
- 艾里亚斯：东边货仓，门厚。……没电。配电箱在泵站外壁，黄漆的。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯探出半步，自己去看门洞。〕
- 〔供电〕
- （频道里，继电器一排咔哒响过去。刮擦停了。）
- 艾里亚斯：别出声。
- （静。）
- （脚下，泵转起来。刮擦重新开始——低了，齐腰。）
- 艾里亚斯：它在听泵。好——泵比我响。
- 艾里亚斯：回桥头那块面板，开货仓门。慢点，门轴会叫。
- 罗温（压低声音）：现在安全了，出来吧。
- 艾里亚斯：我还听得见它。你确定？
- 艾里亚斯：……我不出去。
- 〔开闸〕
- 艾里亚斯：它听见门轴了。往下走了，井底。门轴一叫，它就掉头。记住这个。
- 艾里亚斯：货仓。最里排货架前。开声纳。……它会擦着你过去。推进器拉最低档。它进去了——补光拍。光它不在乎。拍完关。出来。关门。
- 艾里亚斯：你要是现在掉头，我不怪你。
- 罗温（压低声音）：快点。
- 艾里亚斯：我比你急。我就在它旁边。
- 〔驶入货仓，停在最里排货架前，打开主动声纳〕
- 艾里亚斯：刮声没了。……罗温，它不在我这儿了。那它在哪儿？
- 〔声纳回波里，一团东西越来越近〕
- （艇壳外侧一道长长的刮擦，从艇尾拖到艇首。频道里没有呼吸声。）
- （八秒。）
- 艾里亚斯：……好。别说话是对的。
- 〔它绕过艇身，钻进最里排货架之间〕
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：拍到了？……这回别骗我。
- 艾里亚斯：关声纳。慢慢出来，回去关门。
- 〔驶出货仓时推进过快〕
- 艾里亚斯：慢——它转过来了。
- （四秒。刮擦挪开了。）
- 〔关闸隔离〕
- （门轴长叫。货仓里的刮擦猛地转向门口。闸落。一声闷撞。）
- 艾里亚斯：那一下……是门，还是它？它关进去了吗？
- 罗温：搞定了。
- 艾里亚斯：……门关死了？
- 艾里亚斯：……我出来。
- 艾里亚斯：走廊。尽头值班室，有观察窗，门能锁。
- 艾里亚斯：镜头往左打到底，拍走廊口。洗出来我已经到了——有东西，到了再说。
- 〔艾里亚斯沿内侧走廊撤离〕
- 〔撤离途中录像，画面人物：艾里亚斯停下回望货仓闸门。〕
- 艾里亚斯：我在观察窗后面了，门锁上了。应急电只走货仓那一路，我这边还是黑的。我把头灯朝后举着——你拍。片子比我眼睛尖。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯确认身后，没有看潜艇。〕
- 艾里亚斯：看完了？……这回你别急着说安全。我数三下。一。……二。……三。
- 艾里亚斯：那天我也这么等过。喊到第九个，没人应。
- 艾里亚斯：你还在线吗？
- 罗温：走吧。
- 艾里亚斯：……你之前说什么都没有。
- 艾里亚斯：算了。谢了，真的。我先走了。
- 艾里亚斯：我关频道了，省电。下面见。
- （咔哒。）
- （被动声纳：泄水井方位，两下，一停。）
- 罗温：万斯？
- （地面频道：有载波。没人说话。）
- 〔离港〕
