# 第一关对白稿 C

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：入口坐标，我念一遍：X 11，Y 16，深度1012。输进导航台，过A气闸走维修湾——那条缝只有你的艇挤得进去。
- 万斯：……慢点开，罗温。我在这条频道上。
- 罗温：为什么只派我一个人
- 万斯：只有你的艇进得了那条维修湾。
- 万斯：别的……我也想知道。
- 〔驶到A气闸〕
- 万斯：航点对上了。艇首对门，慢慢靠过去，三米多就刹住，再开门。
- （C-B压力门打开。）
- 万斯：你那边读数在跳——罗温？说句话，随便说句——
- 万斯：罗温？你那边——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：……有人吗……接驳港，有没有人……我是艾里亚斯，修泵的。桥断了，我过不去。……谁都行。
- 罗温：你到底是谁
- 艾里亚斯：刚说了，艾里亚斯，修泵的。你要看工牌，先把我弄出去。
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：……好。就这样。别打灯，别再敲那个。听着就行。
- （金属刮擦声从墙后传来。）
- 艾里亚斯：听见没……墙后面。那就是它。我拿眼睛找过，什么都没有。只在监控底片上见过。
- 艾里亚斯：你那儿有外景机吧？到01号机位，对着我这边拍一卷。洗出来，告诉我上面有什么。
- 罗温：还要多久
- 艾里亚斯：……我在数呼吸。你那边好了就告诉我。反正我哪儿也去不了。
- 〔玩家在01曝光，显影，分析：画面中有东西伸手靠近艾里亚斯。画面人物：艾里亚斯背贴墙，脸背向潜艇。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：这里到底发生了什么
- 艾里亚斯：……你不肯说片子上有什么。那就是很糟。
- 艾里亚斯：警报响了，泄压门一道一道往下落。我在泵房，喊名字，没人回。
- 艾里亚斯：等我出来，港里只剩水声。后来闸门也开了。谁开的，我没看见。
- （金属刮擦声从墙后传来。）
- 艾里亚斯：我在它旁边待了两个钟头，不敢动。你得把它从门口弄走——弄走了，我就从操作室后面那条内侧走廊撤。
- 艾里亚斯：东边有个货仓，门够厚，关得住它。可事故以后那边断了电。配电箱在02，坐标在你屏上。先去把应急电拉起来。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯在卷帘门旁等待。〕
- 〔供电〕
- 艾里亚斯：配电绿了，我这边指示灯亮了一排。我还捂着头灯。……回01那块面板，开货仓门。慢点——门轴会叫。
- 罗温（压低声音）：之前这里发生了什么
- 艾里亚斯：我刚说了……我就知道这些。闸门谁开的，我真没看见。
- 〔开闸〕
- 艾里亚斯：门开了。下一步你不会喜欢——你得开进03货仓，进到最里面，再打声纳，把它叫过来。
- 艾里亚斯：它进来时会贴着你的艇过去。别动，也别盯着它看。
- 艾里亚斯：它进去了就拍一张。拍到就关声纳，慢慢滑出来，回01关门。别加速。
- 罗温（压低声音）：会没事的
- 艾里亚斯：……嗯。我还在。
- 〔驶入03货仓最深处，打开主动声纳〕
- 艾里亚斯：……它动了。离开我这儿了。往你那边去了。
- 〔声纳红点逼近〕
- 艾里亚斯：别动。它在门口……再近一点……
- 〔红点进仓〕
- 艾里亚斯：进去了。拍它。
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：……拍到了？好。关声纳，出来。回01关门——快，但别出声。
- 〔关闸隔离〕
- 艾里亚斯：……刮声停了。是你吗？它关进去了吗？
- 罗温：你可以出来了
- 艾里亚斯：……你是说，门关死了？
- 艾里亚斯：好。好。我出来。
- 艾里亚斯：我出去了，走操作室后面那条内侧走廊。01的机位对着走廊口——你帮我盯着，拍下来。片子上我身后要是有影子，就喊我名字。
- 〔艾里亚斯沿内侧走廊撤离〕
- 〔撤离途中录像，画面人物：艾里亚斯沿内侧走廊行走。〕
- 艾里亚斯：我在观察窗后面了，门锁上了。……你再拍一张吧。我想知道我身后真的什么都没有。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯站在门后喘息。〕
- 艾里亚斯：……门后面很安静。你还在线吗？
- 罗温：保重
- 艾里亚斯：谢谢。真的。
- 艾里亚斯：值班室在下一层。我路过就翻翻，看那天谁在班上。……下面见。
- 罗温：别关频道
- 艾里亚斯：能听见我，我就一直开着。
- 〔离港〕
