# 第一关对白稿 C

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：接驳港入口坐标，X 11，Y 16，深度1012米。输入左侧导航台，手动驶到气闸前，再沿维修湾通道进主港。
- 罗温：事故报告怎么说的
- 万斯：公司给的口径是：Panacea是修复治疗项目，这一层发生了一次泄压事故。
- 万斯：事故条目只有两句话。剩下的，要你自己去看。
- （C-B压力门打开。）
- 万斯：罗温……信号在……变弱。你还听得——
- 罗温：你是不是早就知道会这样
- 万斯：我知道的不比你多。我——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：有人收到吗？我是接驳港维修员艾里亚斯。我被困在断桥另一边。请回答。
- 罗温：别动，贴着墙待着，我是事故调查员
- 艾里亚斯：好，我不动。我贴着墙。
- 艾里亚斯：调查员？……好。好。先活下来，再调查。
- 艾里亚斯：我在断桥对面，卷帘门旁边。
- 艾里亚斯：等等——你的主动声纳还开着？天哪，快关掉！它听得见！
- 罗温：它是什么？
- 艾里亚斯：我不知道它叫什么。我只知道它听得见你。关掉。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：……安静了。听我说，不要开灯，也不要开主动声纳。只用被动接收。
- （金属刮擦声从墙后传来。）
- 艾里亚斯：听见了吗？那就是它。你的眼睛看不见它，只有摄像机拍得到。
- 艾里亚斯：去01，X60、Y27、深度1012米，拍我这边。等显影完成，到分析台看录像，再用麦克风叫我。
- 〔玩家在01曝光，显影，分析：画面中有东西伸手靠近艾里亚斯。画面人物：艾里亚斯贴墙不动，手套遮住头盔灯。〕
- 罗温：它就在你身后的门里，离你很近
- 艾里亚斯：……就在门里？离我这么近？
- 艾里亚斯：我被它困在这里，不敢出来。你帮我引开它，我就能从操作室出来，走外面的应急走廊。
- 艾里亚斯：这里有个货仓，可以把它诱到里面关起来。不过事故后货仓门断电了。先去02，X42、Y28、深度1012米，靠近配电面板按F，恢复应急电力。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯退进阴影，一动不动地看着潜艇。〕
- 〔供电〕
- 艾里亚斯：好了，听我说。现在回01，X60、Y27、深度1012米，靠近面板按F，把货仓闸门打开。
- 罗温：说说你自己
- 艾里亚斯：我管这层的泵和接驳臂。本来下个月轮岗上去。
- 〔开闸〕
- 艾里亚斯：接下来的操作很危险，你一定仔细听。闸门开后，从X77、Y22、深度1011米驶入03货舱，一直开到仓内X77、Y7、深度1011米，人在仓里了再开启主动脉冲，把它引进来。
- 艾里亚斯：等它完全进仓，先拍一张确认它在里面，再快速停止主动脉冲，安静离开。停止脉冲后低速驶出货舱，返回开门时的01面板（X60 Y27 DEPTH 1012m，回到深度1012米）关闸。
- 罗温：接下来做什么
- 艾里亚斯：从X77、Y22驶入03货舱，开到仓内X77、Y7，再开主动脉冲把它引进来。它进仓后先拍一张。
- 〔诱导入仓并拍摄确认〕
- 艾里亚斯：你已经拍下它在货仓里了。现在停止主动脉冲，低速撤出货舱，返回开门时的01面板（X60 Y27 DEPTH 1012m，回到深度1012米）关闭货仓闸门！
- 〔关闸隔离〕
- 艾里亚斯：你搞定了吗？它关进去了吗？
- 罗温：等一下，我再确认
- 艾里亚斯：好……我等你说。
- 罗温：门关上了，扶着栏杆出来，别回头
- 艾里亚斯：扶着栏杆，不回头。好。
- 艾里亚斯：我现在从控制室出去。你在01，X60、Y27、深度1012米，拍摄我撤离的情况。如果我出了情况，请来救我。
- 〔艾里亚斯沿内侧走廊撤离〕
- 罗温：快到了，你做得很好
- 艾里亚斯：……快到了。
- 〔撤离途中录像，画面人物：艾里亚斯扶着栏杆走，没有回头。〕
- 艾里亚斯：我到内侧门后了。拍下这里的情况，再确认我们能继续往下走。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯回身朝潜艇举手。〕
- 艾里亚斯：……门后面很安静。你还在线吗？
- 罗温：看到值班记录帮我留着
- 艾里亚斯：我本来就想找。你是调查员，你该看到。
- 罗温：我们下面见
- 艾里亚斯：下面见。门那边我想办法。
- 〔离港〕
