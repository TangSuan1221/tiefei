# 第一关对白稿 D

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：坐标发你了，在导航台上。过气闸走维修湾那条缝——全队只有你的艇挤得进去。
- 万斯：缝里开声纳，不然你会亲那面墙。过了门就关——你那块电池我签的字，我知道它几斤几两——至少文件上是这么写的。岸电在里面。慢点开，罗温。我盯着你的点。
- 罗温：为什么只派我一个人。
- 万斯：因为那条缝。
- 万斯：别的……我也想知道。
- 〔驶到A气闸〕
- 万斯：门就在你正前方。门框应力计三天前报过一次撞击。……不是水压。别停，慢慢靠。
- （身后，压力门的液压杆长长泄了一口气。）
- 万斯：你深度读数在跳，载波也在掉——罗温？说句话，随便说句——
- 万斯：罗温？你那边——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：（录音，只在泵起转的那几秒里放）……泵站七，艾里亚斯，修泵的。一个人，断桥对面。……听见请回。小声。
- 罗温：你到底是谁？
- （循环录音在第三遍中途断掉。一声吞咽。）
- 艾里亚斯：有人。……真的有人。
- 艾里亚斯：刚说了，艾里亚斯，修泵的。你要看工牌，先把我弄出去。
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：就这样。我这头走脐带硬线，接港里的固定换能器——窄波束，贴着地板只朝你打——你刚才那声声纳，我记下了方位。你那台是全向的水声电话，你每说一句，整片水都有。
- （水听器：门后，金属刮擦。两下，一停。）
- 艾里亚斯：两下一停。……它在找。
- 艾里亚斯：你们局的艇我修过两条。灯是老镇流器吧？别开——会嗡。
- 艾里亚斯：外景机。桥头灯杆底下，旧机位，正对我这扇门。我头盔转不了，看不见身后——你帮我看。头灯快没电了，我挡着，漏一线。拍下来，告诉我上面有什么。
- 罗温：还要多久？
- 艾里亚斯：……我在数呼吸。你那边好了就告诉我。反正我哪儿也去不了。
- 〔玩家在01曝光，显影，分析：门缝下沿探出三根细长的东西，停在艾里亚斯左脚跟后一掌。画面人物：艾里亚斯背贴墙，脸背向潜艇。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：这里到底发生了什么？
- 艾里亚斯：事故的事，出去再说。
- 艾里亚斯：片子先说。上面有什么？
- （静。）
- 艾里亚斯：门后是井。通港池。
- （水听器：井里，一串气泡上浮。）
- 艾里亚斯：走廊口在井盖正上面。它不挪，我过不去。
- （静。）
- 艾里亚斯：东边货仓，门厚。把它引进去，关门。……没电。配电箱在泵站外壁，黄漆的。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯在卷帘门旁等待。〕
- 〔供电〕
- （水听器：继电器一排咔哒响过去。刮擦停了。）
- 艾里亚斯：别出声。
- （静。）
- （水听器：泵转起来。刮擦重新开始，低了。）
- 艾里亚斯：低了。……它下去了，在听泵。下去也就十来米——井盖我掀不动，它一顶就开。得把它关起来。
- 艾里亚斯：回桥头那块面板，开货仓门。慢点，门轴会叫。
- 罗温（压低声音）：之前这里发生了什么？
- 艾里亚斯：警报，泄压门一道道落。我关在泵房里。
- 艾里亚斯：出来的时候，闸门开着。谁开的——我没看见。
- 〔开闸〕
- 艾里亚斯：它听见门轴了。往下走了，井底。……它听门轴。
- 艾里亚斯：货仓最里面。到了再开声纳。你进仓，我就闭嘴——我的波束会打到它身上。我按载波键：一下是等，两下是拍，打闪光。三十八千赫，它听不见那么高——它听的是门轴，低的。
- 艾里亚斯：你要是现在掉头，我不怪你。
- 罗温（压低声音）：会没事的。
- 艾里亚斯：……嗯。我还在。
- 〔驶入货仓，停在最里排货架前，打开主动声纳〕
- 艾里亚斯：刮声没了。……它不在我这儿了。那它在哪儿？
- 〔声纳回波里，一团东西越来越近〕
- （艇壳外侧一道长长的刮擦，从艇尾拖到艇首。频道里没有呼吸声。）
- 罗温（压低声音）：那是什么声音？
- （艇壳正对你说话的位置，一声闷撞。仪表盘上 HULL 跳了一格。）
- （接收机：急促的三声咔。然后什么都没有。）
- （静。）
- （很久。……咔。咔。）
- 〔它绕过艇身，钻进最里排货架之间〕
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：……拍到了？关声纳。慢慢出来，比你想的还要慢。回去关门。
- 〔关闸隔离〕
- （水听器：门轴长叫。货仓里的刮擦猛地转向门口。闸落。一声闷撞。）
- 艾里亚斯：那一下……是门，还是它？它关进去了吗？
- 罗温：你可以出来了。
- 艾里亚斯：门关死了？
- （四秒。他在等你。）
- 艾里亚斯：你不答，我就当是。（他换了一口气，很长。）我出来。
- 艾里亚斯：走廊。尽头值班室，有观察窗，门能锁。我拔了脐带走——服里的背包够一个钟头。脐带一拔，我也是水声了。少说话，你也是。
- 艾里亚斯：镜头往左打到底，拍走廊口。洗出来的时候我该到了。
- 〔艾里亚斯沿内侧走廊撤离〕
- 〔撤离途中录像，画面人物：艾里亚斯沿内侧走廊行走。〕
- 艾里亚斯：墙上有插口——插回去了，又是线了。……我在观察窗后面，门锁上了。这边是黑的。我回身朝你举灯——你拍。我背后，你帮我看着。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯站在门后喘息。〕
- 艾里亚斯：看完了？片子上要是还有别的东西，现在就说。……我数三下。一。……二。……三。……好，只有我。
- 艾里亚斯：那天我也这么等过。广播点名，从一叫到九，一个都没应。叫到我，我在泵房里喊到嗓子破——门外听不见。名单上，我也是没应。
- 艾里亚斯：你还在线吗？……我连你叫什么都不知道。
- 罗温：保重。
- 艾里亚斯：谢谢。真的。
- 艾里亚斯：值班室在下一层。我路过就翻翻，看那天谁在班上。……下面见。
- 罗温：别关频道。
- 艾里亚斯：……开着。我不说话，每半分钟按一下载波。哪天没有咔声了——别喊我。那是我在躲。
- （频道开着。他不说话。接收机上一声高音咔。……三十秒。……咔。）
- （被动声纳：货仓方位一个声源，不动。泄水井方位，又一个。水听器里，两下，一停。）
- （……三十秒。……四十秒。……五十秒。没有咔声。）
- （……咔。）
- （地面频道：载波回来了。偶尔一声按键的咔哒。）
- 万斯：语音全断了，我只收得到遥测。有一阵，你的点一动没动。……我没往上报。
- 万斯：你艇壳读数掉了一格。我看见了，没写。
- 万斯：往下走吧。我还盯着。
- 〔离港〕
