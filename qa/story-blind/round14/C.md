# 第一关对白稿 C

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：坐标发你了，在导航台上。过气闸走维修湾那条缝——全队只有你的艇挤得进去。
- 万斯：缝里开声纳，不然你会亲那面墙。过了门就关——你那块电池我签的字，我知道它几斤几两——至少文件上是这么写的。岸电在里面。慢点开，罗温。我盯着你的点。
- 罗温：这里让我不舒服。
- 万斯：你一向讨厌人多。现在下面一个人都没有，你倒不舒服了。
- 万斯：……说话，罗温。你说话我就知道你还在。
- 〔驶到A气闸〕
- 万斯：门就在你正前方。门框应力计三天前报过一次撞击。……不是水压。别停，慢慢靠。
- （身后，压力门的液压杆长长泄了一口气。）
- 万斯：你深度读数在跳，载波也在掉——罗温？说句话，随便说句——
- 罗温：我有点怕。
- 万斯：……罗温，慢慢来，我在——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：（录音，只在泵起转的那几秒里放）……泵站七，艾里亚斯，修泵的。一个人，断桥对面。……听见请回。小声。
- 罗温：坚持住，我马上过来。
- （循环录音在第三遍中途断掉。一声吞咽。）
- 艾里亚斯：有人。……真的有人。
- 艾里亚斯：过不来，桥断了——你别过来。
- 艾里亚斯：……你在对面？我把夹钳抬一下。你看不见也没关系——拍下来，就知道我是真的。
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：就这样。我这头走脐带硬线，接港里的固定换能器——窄波束，贴着地板只朝你打。你那台是全向的水声电话，你每说一句，整片水都有。
- （水听器：门后，金属刮擦。两下，一停。）
- 艾里亚斯：两下一停。……它在找。
- 艾里亚斯：你们局的艇我修过两条。灯是老镇流器吧？别开——会嗡。
- 艾里亚斯：外景机。桥头灯杆底下，旧机位，正对我这扇门。我头盔转不了，看不见身后——你帮我看。头灯快没电了，我挡着，漏一线。拍下来，告诉我上面有什么。
- 〔玩家在01曝光，显影，分析：门缝下沿探出三根细长的东西，停在艾里亚斯左脚跟后一掌。画面人物：艾里亚斯的一只夹钳离开栏杆几厘米，朝黑暗中的潜艇极轻地示意。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：别怕，什么都没有。
- 艾里亚斯：没什么？那门后面是什么在刮？
- 艾里亚斯：……算了。
- （静。）
- 艾里亚斯：门后是井。通港池。
- （水听器：井里，一串气泡上浮。）
- 艾里亚斯：走廊口在井盖正上面。它不挪，我过不去。
- （静。）
- 艾里亚斯：东边货仓，门厚。把它引进去，关门。……没电。配电箱在泵站外壁，黄漆的。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯探出半步，自己去看门洞。〕
- 〔供电〕
- （水听器：继电器一排咔哒响过去。刮擦停了。）
- 艾里亚斯：别出声。
- （静。）
- （水听器：泵转起来。刮擦重新开始，低了。）
- 艾里亚斯：低了。……它下去了，在听泵。下去也就十来米——井盖我掀不动，它一顶就开。得把它关起来。
- 艾里亚斯：回桥头那块面板，开货仓门。慢点，门轴会叫。
- 罗温（压低声音）：现在安全了，出来吧。
- 艾里亚斯：我还听得见它。你确定？
- 艾里亚斯：……我不出去。
- 〔开闸〕
- 艾里亚斯：它听见门轴了。往下走了，井底。……它听门轴。
- 艾里亚斯：货仓最里面。到了再开声纳。离得远，你压着说它听不清；它贴上来，就别开口。
- 艾里亚斯：你要是现在掉头，我不怪你。
- 罗温（压低声音）：快点。
- 艾里亚斯：我比你急。它是下去了，可井盖就在我脚底下。
- 〔驶入货仓，停在最里排货架前，打开主动声纳〕
- 艾里亚斯：刮声没了。……它不在我这儿了。那它在哪儿？
- 〔声纳回波里，一团东西越来越近〕
- （艇壳外侧一道长长的刮擦，从艇尾拖到艇首。频道里没有呼吸声。）
- （八秒。）
- 艾里亚斯：……好。别说话是对的。
- 艾里亚斯：等它钻进货架再拍，打闪光。充电那一声尖——别早按。
- 〔它绕过艇身，钻进最里排货架之间〕
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：拍到了？……这回别骗我。
- 艾里亚斯：关声纳。慢慢出来，回去关门。
- 〔驶出货仓时推进过快〕
- 艾里亚斯：你推进器在叫。……停一下。
- （四秒。水听器里，刮擦挪开了。）
- 〔关闸隔离〕
- （水听器：门轴长叫。货仓里的刮擦猛地转向门口。闸落。一声闷撞。）
- 艾里亚斯：那一下……是门，还是它？它关进去了吗？
- 罗温：搞定了。
- 艾里亚斯：……搞定了？你上回也说没什么。
- 艾里亚斯：我自己听。
- （十秒。频道里只有他压着的呼吸。）
- 艾里亚斯：……没有刮擦。我信耳朵，不信你。我出来。
- 艾里亚斯：走廊。尽头值班室，有观察窗，门能锁。我拔了脐带走——服里的背包够一个钟头。脐带一拔，我也是水声了。少说话，你也是。
- 艾里亚斯：镜头往左打到底，拍走廊口。洗出来的时候我该到了。
- 〔艾里亚斯沿内侧走廊撤离〕
- 〔撤离途中录像，画面人物：艾里亚斯停下回望货仓闸门。〕
- 艾里亚斯：我在观察窗后面了，门锁上了。这边是黑的。我回身朝你举灯——你拍。我背后，你帮我看着。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯确认身后，没有看潜艇。〕
- 艾里亚斯：看完了？……这回你别急着说安全。片子上要是还有别的，现在就说。我数三下。一。……二。……三。
- 艾里亚斯：那天我也这么等过。广播点名，从一叫到九，一个都没应。叫到我，我在泵房里喊到嗓子破——门外听不见。名单上，我也是没应。
- 艾里亚斯：你还在线吗？……我连你叫什么都不知道。
- 罗温：走吧。
- 艾里亚斯：……你走吧。下一层要是再碰上，我先听，再听你。
- 艾里亚斯：我关频道了，省电。下面见。
- （咔哒。）
- （被动声纳：货仓方位一个声源，不动。泄水井方位，又一个。水听器里，两下，一停。）
- （地面频道：载波回来了。偶尔一声按键的咔哒。）
- 万斯：语音断了四十分钟。你的点倒一直在跳——有十一分钟一动没动。……那十一分钟我没往上报。
- 万斯：你那边有人在说话。他叫你什么？……没叫？好。
- 万斯：往下走吧。我还盯着。
- 〔离港〕
