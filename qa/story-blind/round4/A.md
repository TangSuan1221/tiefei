# 第一关对白稿 A

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：坐标发你了，在导航台上。过气闸走维修湾那条缝——全队只有你的艇挤得进去。
- 万斯：……慢点开，罗温。我盯着你的点。
- 罗温：为什么只派我一个人
- 万斯：只有你的艇进得了那条维修湾。
- 万斯：别的……我也想知道。
- 〔驶到A气闸〕
- 万斯：门就在你正前方。慢慢靠，别蹭它——上回有条艇蹭了一下，密封圈漏了一礼拜。
- （C-B压力门打开。）
- 万斯：你那边读数在跳——罗温？说句话，随便说句——
- 万斯：罗温？你那边——
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：……有人吗……接驳港，有没有人……我是艾里亚斯，修泵的。桥断了，我过不去。……谁都行。
- 罗温：你到底是谁
- 艾里亚斯：刚说了，艾里亚斯，修泵的。你要看工牌，先把我弄出去。
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：……就这样。我用的是喉麦，嘴都不张。你那边也别打灯——镇流器会嗡。
- （门后传来金属刮擦声。）
- 艾里亚斯：听见没……门后面。我背靠的这扇。我看过去，那儿就是一扇门。……可监控底片上，门缝是鼓出来的。
- 艾里亚斯：你那儿有外景机吧？桥头灯杆底下有个旧机位，你屏上是01。对着我拍一卷，洗出来，告诉我上面有什么。
- 罗温：还要多久
- 艾里亚斯：……我在数呼吸。你那边好了就告诉我。反正我哪儿也去不了。
- 〔玩家在01曝光，显影，分析：画面中有东西伸手靠近艾里亚斯。画面人物：艾里亚斯背贴墙，脸背向潜艇。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：这里到底发生了什么
- 艾里亚斯：……你不肯说片子上有什么。那就是很糟。
- 艾里亚斯：警报响了，泄压门一道一道往下落。我在泵房，喊名字，没人回。
- 艾里亚斯：等我出来，港里只剩水声。后来闸门也开了。谁开的，我没看见。
- （门后传来金属刮擦声。）
- 艾里亚斯：两个钟头了。你得把它从门口弄走——弄走了，我就从操作室后面那条内侧走廊撤。
- 艾里亚斯：东边有个货仓，门够厚，关得住它。可事故以后那边断了电。配电箱在泵站外壁，黄漆那个——你屏上标的02。先把应急电拉起来。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯在卷帘门旁等待。〕
- 〔供电〕
- （继电器一排咔哒响过去。门后的刮擦停了。）
- 艾里亚斯：……别出声。
- （门后传来金属刮擦声。）
- 艾里亚斯：……又开始了。比刚才近。配电绿了。回桥头那块面板，开货仓门。慢点——门轴会叫。
- 罗温（压低声音）：之前这里发生了什么
- 艾里亚斯：我刚说了……我就知道这些。闸门谁开的，我真没看见。
- 〔开闸〕
- 艾里亚斯：……它听见门轴了。刮声在往那边转。记住它是怎么转的。
- 艾里亚斯：下一步你不会喜欢——开进货仓，进到最里面，再打声纳，把它叫过去。
- 艾里亚斯：它会贴着你的艇过去。你会听见船壳响。别回应。等它进去了再拍，拍到就关声纳，慢慢出来，回去关门。
- 罗温（压低声音）：会没事的
- 艾里亚斯：……嗯。我还在。
- 〔驶入货仓最深处，打开主动声纳〕
- 艾里亚斯：……刮声没了。它不在我这儿了。
- 艾里亚斯：……我听不见它了，罗温。你那边呢？
- 〔声纳回波里，一团东西越来越近〕
- （艇壳外侧一道长长的刮擦，从艇尾拖到艇首。频道里，他的呼吸也停了。）
- 〔它进了货仓深处〕
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：……拍到了？关声纳。慢慢出来，比你想的还要慢。回去关门。
- 〔关闸隔离〕
- 艾里亚斯：……刮声停了。是你吗？它关进去了吗？
- 罗温：你可以出来了
- 艾里亚斯：……门关死了？
- 艾里亚斯：……我出来。
- 艾里亚斯：我出去了，走操作室后面那条内侧走廊。桥头那个旧机位对着走廊口，拍下来。
- 艾里亚斯：等你洗出来，我已经到了。片子上我身后要是有东西……到了再告诉我。别在路上说。
- 〔艾里亚斯沿内侧走廊撤离〕
- 〔撤离途中录像，画面人物：艾里亚斯沿内侧走廊行走。〕
- 艾里亚斯：我在观察窗后面了，门锁上了。……你再拍一张吧。我想知道我身后真的什么都没有。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯站在门后喘息。〕
- 艾里亚斯：……门后面很安静。你还在线吗？
- 罗温：保重
- 艾里亚斯：谢谢。真的。
- 艾里亚斯：值班室在下一层。我路过就翻翻，看那天谁在班上。……下面见。
- 罗温：别关频道
- 艾里亚斯：能听见我，我就一直开着。
- （载波断了。货仓方向传来一下刮擦。只有一下。）
- 〔离港〕
