# 第一关对白稿 A

〔〕为玩家操作与画面，罗温的台词即玩家在麦克风里说的话。

- 万斯：坐标发你了，在导航台上。过气闸走维修湾那条缝——全队只有你的艇挤得进去。
- 万斯：主动声纳我给你开着——不开，那条缝你看不见。慢点开，罗温。我盯着你的点。
- 罗温：事故报告怎么说的。
- 万斯：两行。“Panacea项目区泄压事故，幸存者待确认。”
- 万斯：……签字栏是空的。
- 〔驶到A气闸〕
- 万斯：门就在你正前方。慢慢靠，别蹭它——上回有条艇蹭了一下，密封圈漏了一礼拜。
- （C-B压力门打开。）
- 万斯：你深度读数在跳，载波也在掉——罗温？说句话，随便说句——
- 罗温：你是不是早就知道会这样。
- 万斯：知道什么？——签字栏空着不代表——罗温，报压差，报压差！
- （万斯的载波断开，频道里只剩底噪。）
- 艾里亚斯：（录音，循环）……泵站七，艾里亚斯，修泵的。一个人，断桥对面。……听见请回。小声。
- 罗温：别动，贴着墙待着，我是事故调查员。
- （循环录音在第三遍中途断掉。一声吞咽。）
- 艾里亚斯：有人。……真的有人。
- 艾里亚斯：……墙？你看得见我？
- 艾里亚斯：猜的吧。猜对了。我一直贴着，不动。
- 艾里亚斯：调查员。……那你记一笔：泵站七，一个活的。
- 艾里亚斯：断桥对面，卷帘门旁边那扇检修门。我背靠着它，左手攥着栏杆。
- 艾里亚斯：那是什么声音——是你在打声纳？关掉。现在就关。它听得见。
- 罗温：它是什么？
- 艾里亚斯：别问。关。
- 〔玩家关闭主动声纳〕
- 艾里亚斯：就这样。喉麦，每口气我都得咽回去。你那边也别打灯——镇流器会嗡。
- （门后，金属刮擦声。两下，一停。）
- 艾里亚斯：两下一停。它找东西的时候就这么敲。那扇门三天前就鼓了。我转不了头——颈环一动就咔哒响。
- 艾里亚斯：你艇上有外景机吧？开到桥头灯杆底下，那是旧机位，正对我这扇门。我头灯还剩一档，拿指缝漏一点出来——够你拍。洗出来，告诉我上面有什么。
- 〔玩家在01曝光，显影，分析：画面中有东西伸手靠近艾里亚斯。画面人物：艾里亚斯贴墙不动，指缝间漏出一线头灯光。〕
- 艾里亚斯：……洗出来了？上面有什么？告诉我。
- 罗温（压低声音）：它就在你身后的门里，离你很近。
- 艾里亚斯：……从门缝里？
- 艾里亚斯：……你让我贴着墙的。
- （频道里极轻的一声金属响。刮擦停了。三秒。）
- （刮擦重新开始，节奏没变。）
- 艾里亚斯：……我离开门了。它没听见。
- （静。）
- 艾里亚斯：门后那间是泄水井，底下通港池。它从那儿下去，也从那儿上来。
- 艾里亚斯：内侧走廊口就在井盖正上面。它不挪窝，我过不去。东边有个货仓，门够厚，关得住它。
- 艾里亚斯：可事故以后那边断了电。配电箱在泵站外壁，黄漆那个，你那边的图上应该有。先把应急电拉起来。
- 〔之后经过01时补拍一卷，画面人物：艾里亚斯退进阴影，一动不动地看着潜艇。〕
- 〔供电〕
- （频道里，继电器一排咔哒响过去。刮擦停了。）
- 艾里亚斯：别出声。
- （静。）
- （脚下，泵转起来。刮擦重新开始——低了，齐腰。）
- 艾里亚斯：它在听泵。好——泵比我响。
- 艾里亚斯：回桥头那块面板，开货仓门。慢点，门轴会叫。
- 罗温（压低声音）：说说你自己。
- 艾里亚斯：现在？……七年，这层的泵。每颗螺丝我都拧过。
- 艾里亚斯：现在听它们转，一颗都认不出来。去开门吧。
- 〔开闸〕
- 艾里亚斯：它听见门轴了。往下走了，井底。门轴一叫，它就掉头。记住这个。
- 艾里亚斯：货仓。最里面。开声纳。……它会擦着你过去。推进器别碰。进去了——拍。拍完关。出来。关门。
- 艾里亚斯：你要是现在掉头，我不怪你。
- 罗温（压低声音）：接下来做什么。
- 艾里亚斯：货仓，最里面。……别再让我说话。
- 〔驶入货仓最深处，打开主动声纳〕
- 艾里亚斯：刮声没了。……罗温，它不在我这儿了。那它在哪儿？
- 〔声纳回波里，一团东西越来越近〕
- （艇壳外侧一道长长的刮擦，从艇尾拖到艇首。频道里没有呼吸声。）
- （八秒。）
- 艾里亚斯：……好。别说话是对的。
- 〔它进了货仓深处〕
- 〔拍摄入仓确认并分析〕
- 艾里亚斯：拍到了？……别告诉我它长什么样。
- 艾里亚斯：关声纳。慢慢出来，比你想的还要慢。回去关门。
- 〔关闸隔离〕
- （门轴长叫。货仓里的刮擦猛地转向门口。闸落。一声闷撞。）
- 艾里亚斯：它刚才就是这么转的。听见门轴就回头。
- 艾里亚斯：那一下……是门，还是它？它关进去了吗？
- 罗温：等一下，我再确认。
- （被动声纳：货仓方位，一个声源，不动。）
- 艾里亚斯：我等你说。
- 罗温：门关上了，扶着栏杆出来，别回头。
- 艾里亚斯：扶着栏杆。……不回头。
- 艾里亚斯：我出去了，走操作室后面那条内侧走廊。尽头有间带观察窗的值班室，门能锁。桥头那个位置，镜头往左打到底，就是走廊口。拍下来。
- 艾里亚斯：等你洗出来，我已经到了。片子上我身后要是有东西，到了再告诉我。别在路上说。
- 〔艾里亚斯沿内侧走廊撤离〕
- 罗温：快到了，你做得很好。
- 艾里亚斯：快到了？……你又看不见我。
- 艾里亚斯：……不过你说对了。还剩十几米。腿在抖。
- 〔撤离途中录像，画面人物：艾里亚斯扶着栏杆走，没有回头。〕
- 艾里亚斯：我在观察窗后面了，门锁上了。应急电只走货仓那一路，我这边还是黑的。我把头灯朝后举着——你拍。片子比我眼睛尖。
- 〔玩家在01拍摄撤离结果并分析，画面人物：艾里亚斯回身朝潜艇举手。〕
- 艾里亚斯：看完了？……别说话。我数三下。你没出声，就是只有我。一。……二。……三。
- 艾里亚斯：那天泵房里也只剩我一个。我挨个喊名字，喊到第九个，就不喊了。
- 艾里亚斯：你还在线吗？
- 罗温：看到值班记录帮我留着。
- 艾里亚斯：……我刚说九个人。你要的是表。
- 艾里亚斯：值班表在下一层。那天那一页，我也想看。
- 罗温：我们下面见。
- 艾里亚斯：下面见。我从里面找路。
- 艾里亚斯：我关频道了，省电。下面见。
- （咔哒。）
- （被动声纳：货仓方位，一下。随后，泄水井方位，两下，一停。）
- 罗温：万斯？
- （地面频道：有载波。没人说话。）
- 〔离港〕
