# 盲测轮次 3 · 判定书

**设计问题**：声呐是"按下就拿到信息"的三档离散，还是"发声—僵直—回波"的三拍承诺？

**结论：方案甲（三拍承诺）胜，且六项准入线全过。定为声呐 slot 的基线。**

---

## 〇、前一版判定书作废

本文件的第一版是对着 `sonar3-report.md` 的一个**已失效快照**写的，结论是"两套都不进线，开方案丁救火"。那份结论现已全部作废，原因不在判断，在被判断的数字：

写完那一版之后几分钟，实验台修掉了一个量纲错误并重跑了本轮。旧报告用**行动条数**统计感知与移动的占比，而甲的一次感知会摊成八条（发声一条 + 僵直七拍），乙的一次感知只有一条。同一件事在甲那里被记八次、在乙那里被记一次，于是：

- 甲的移动占比被压成 **6.46%**，看上去像"逃生退化成了原地声呐模拟器"；
- 甲的感知占比被顶到 **57.1%**，看上去像"玩家一半时间在打声呐"。

改成**呼吸时间**口径之后，两者在同一个守恒量上比较，甲的移动是 **24.2%**，是全场最健康的移动占比。我上一版最重的那条否决意见——"这是一个逃出潜艇的游戏，而甲 93.5% 的回合不在移动"——**是量纲造出来的幻觉**。

同一次修正也改动了玩家大脑与缓存经济，甲的三分位存活率从 58.0 → 83.3 → **42.0**（高技巧反而死得多）变成了 40.3 → 82.0 → **83.5**（单调上升）。我据此写的第二条否决意见"机制在惩罚理解它的人"，同样不成立。

记在这里是因为这件事本身就是教训：**匿名化解决了"我偏爱谁"，解决不了"我量错了什么"。** 一个在两个变体之间不守恒的统计口径，比设计者的偏心更危险，因为它看起来像客观数据。第四轮的报告生成器必须在正文里显式标注每个占比的口径。

## 一、结论依据

### 甲（三拍承诺）六项全过

| 条件 | 要求 | 甲 | 乙 |
|---|---|---|---|
| 技巧表达度 | ≥ 0.55 | **0.624** ✅ | 0.392 ❌ |
| 失败可归因 | ≥ 0.50 | **0.832** ✅ | 0.754 ✅ |
| 张力曲线 | ≥ 0.50 | **0.693** ✅ | 0.509 ✅ |
| 感知时间占比 | ≥ 20% | 69.9% ✅ | 43.5% ✅ |
| 听者死因占比 | ≥ 35% | **60.0%** ✅ | 35.8% ✅ |
| 总分（剔除意外率） | ≥ 0.62 | **0.736** ✅ | 0.735 ✅ |

### 甲赢在四件事上

**① 五个档位全都在用。** 起手档位内部最高频 **33.4%**，有效多样性 **4.65 档**，废档 **0**。对比乙：最高频 53.6%、多样性 2.62。这是两轮以来第一次出现"玩家真的在按情境挑档位"，而不是算出一个性价比最优解然后一直按它。

**② 设计的每一件工具都被触发了。** 定向脉冲 8.70 次/局、照射致聋 2.27 次/局、中途中止 7.13 次/局、听到缓存 13.61 次而真的去取 10.40 次。没有一件是摆设。乙的同类数字（致聋 1.25、走过缓存却没拿 13.53）说明它的玩家在盲目赶路。

**③ 四条失败路径同时存在。** 甲的死因是 listener 60.0% / trauma 20.5% / asphyxiation 17.3% / lost 2.1%。乙是 asphyxiation 40.0% 压过 listener 35.8%——按判读要点第五条，这意味着**招牌威胁正在被玩家单方面取消**：乙的玩家学会了不发声，于是听者退场，游戏变回一个憋气计时器。甲用"噪音已经付出去了、你现在必须站着等回波"把这条退路堵死了。

**④ 时间结构是对的。** 甲的休息只占 1.55%、屏息 1.84%；乙是休息 7.39% + 屏息 14.82%。一个玩家 22% 的回合在原地调息的恐怖游戏，节奏是塌的。这也解释了乙为什么张力曲线只有 0.509。

### 乙的否决项

技巧表达度 **0.392**，低于 0.55。配合"窒息死因超过听者"，乙的形态结论可以定案了：**即时解算让声呐变成一次采购，而采购没有技巧可言。** 这是这个结论第二次独立复现（轮次 1 已有同向证据），**纯即时档位这条路封死，不再开分支。**

## 二、甲的两处真问题（第四轮要打的靶子）

甲过线不等于甲完美。剔掉上一版那些幻觉之后，剩下两条是真的：

**① 恢复余地 0.220**（乙 0.766）。这是甲全部八项里唯一的低分，而且低得离谱。含义是：**甲一旦开始崩，就没有回头路。** 承诺结构天然如此——你在最需要机动的时候恰好把自己钉住了。恐怖游戏需要"差一点就死掉然后爬回来"的时刻，那是整个体验里最强的一拍，甲现在几乎不产生这种时刻。

**② `empty-echo` 558.8 次/百死。** 平均每次死亡背后 5.6 次空回波。按判读要点第七条，这不是可复盘的战术失误，是**机制诱导的无用功**，它虚高了甲名义上的可归因性 0.832。

另有两条记在案上，但不在本 slot 解决：

- `revisit-loop` 甲 667.6 / 乙 1055.1，两个变体都是第一大误判。这是**导航**问题不是声呐问题，玩家在已知区域里兜圈子。应当单开一个 slot（地图记忆 / 路径承诺），不要塞进声呐轮次里，否则第四轮又会变成两个变量同时动。
- 甲的可学习性 0.616（乙 1.000）。三拍系统确实更难学，这是深度的合理代价，但如果第四轮它继续下滑，就要开始还债。

## 三、第四轮（方案丁）

**基线 = 方案甲原样**，不许改一个字。挑战者 = 方案丁，只许动下面三条，且必须瞄准上一节那两处真问题。

**丁-1 ｜ 让僵直期成为可以反悔的赌局，而不是单向的锁（治恢复余地）**
僵直期每一拍给出一组真实互斥的选项，而不是只有"继续听 / 全盘作废"：
- **续压**：多等一拍，半径 +1、区间收窄。
- **截断取半**：立刻结束，拿到保真度打折的**部分**回波。和作废的区别是本质的——作废是惩罚，取半是决策。
- **转向主瓣**：回波返回前改指向，用已经花掉的噪音换一个新方向，代价是保真度下降。
- **贴壁**：本拍不收回波，换取本拍不被听者定位。

"贴壁"和"截断取半"就是甲缺的那条回头路：崩盘开始时，玩家手里得有一个能止损的按钮。

**丁-2 ｜ 空回波必须携带否定信息（治 empty-echo）**
取消"什么都没有"这个返回值。半径内无目标时返回**该扇区在本拍确认为空**，写进信念图，带时效。这个标记必须真的影响 `frontierValue` / `moveUtility` 的导航决策，否则它只是个假收益。做对了 `empty-echo` 应当基本消失，而可归因性不降。

**丁-3 ｜ 收益随承诺增长，风险封顶（治恢复余地）**
僵直期听者的收敛速度在第 3 拍之后不再增加，但回波质量继续随拍数上升。深度承诺应该是"贵"，不该是"越来越可能直接死"。

**不做的事**：上一版的丁-4（同舱不得连续深扫）和丁-5（合并高档位）**撤销**。丁-4 是为了救 6.46% 的移动占比，而那个数字是量纲幻觉，真实值 24.2% 已经很健康，强加这条约束只会破坏已经正确的节奏。丁-5 是为了砍"废档"，而现在废档为 0、五档全用，合并会直接毁掉甲最大的优点。

**第四轮准入线**（在六项之上加两项，都对着这一轮的真问题）：

| 条件 | 要求 |
|---|---|
| 技巧表达度 | ≥ 0.55 |
| 三分位存活率 | 单调不降 |
| 失败可归因 | ≥ 0.50 |
| 张力曲线 | ≥ 0.50 |
| 听者死因占比 | ≥ 35% |
| 总分（剔除意外率） | ≥ 0.62 |
| **恢复余地** | **≥ 0.50**（甲 0.220，这是本轮要买的东西） |
| **`empty-echo`** | **≤ 100 次/百死**（甲 558.8） |
| 起手档位内部最高频 | ≤ 55% |
| 废档位 | 0 |

最后两项是**守成条款**：丁不许为了买恢复余地而赔掉甲已经赢下的档位多样性。
