# Harbor scanned surfaces

These locally served 2K JPG maps are CC0 assets from Poly Haven:

- **Rusty Metal Sheet**, Amal Kumar: https://polyhaven.com/a/rusty_metal_sheet — painted sheet, approximately 2 m across.
- **Metal Plate**, Rob Tuytel: https://polyhaven.com/a/metal_plate — diamond tread, approximately 0.5 m across.

Channels: diffuse in sRGB; OpenGL normal and roughness in linear data space.
Source URLs, byte counts and SHA-256 hashes are recorded in `sources.json`.
Acquisition script: `tools/fetch-harbor-textures.mjs`.

License information: https://polyhaven.com/license (CC0).
No remote runtime requests: the game loads the maps from this directory.
