# Living-deck hero assets: sources and licences

All nine GLBs in this folder (`glass-blast-door`, `valve-manifold`, `security-post`, `manager-office`,
`laundry-row`, `ballast-rack`, `atrium-balcony`, `gate-f`, `cocoon-corpse`) are generated headlessly by
`tools/blender/build-living-<name>.py` and the shared library `tools/blender/living_common.py`
(Blender 4.x, `blender -b --factory-startup -P <script>`). Geometry is procedural.
Textures are baked from the procedural authoring shaders listed below into ≤2K JPEG atlases
that are embedded in each GLB.

`living-diver-alex.glb` was not produced by these scripts. `cocoon-corpse.glb` is the only cocoon actor
(loaded by `living-cocoon.ts`, which rebinds its materials at runtime; it carries no baked textures).

## Third-party inputs (all CC0)

### Poly Haven texture scans — `src/`

The 2K JPG sets (`*_diff_2k`, `*_nor_gl_2k`, `*_rough_2k`, `*_arm_2k`) were downloaded from
`https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/<id>/`. Licence: CC0 1.0
(https://polyhaven.com/license). They are used only as inputs to the bake; the GLBs contain derived
atlases, not the originals.

| id | used as (`scan=` key) |
|---|---|
| rusty_painted_metal | `rusty_painted_metal` |
| rust_coarse_01 | `rust_coarse` |
| dirty_carpet | `carpet` |
| wood_table_worn | `wood` |
| fabric_leather_02 | `leather` (also skin, leaves, stems) |
| rough_linen | `linen` (cloth, uniforms, paper) |
| rubber_tiles | `rubber` (seals, cocoon slime) |
| painted_metal_shutter | `shutter` (painted panels, decal base) |
| green_metal_rust | `green_rust` (brass patina) |
| worn_tile_floor | `tile` (enamel, ceramic, planters) |

Pages: `https://polyhaven.com/a/<id>`.

The `src/` folder is about 110 MB. It sits under `public/`, so a Vite build copies it into `dist/`.
The runtime does not need it. Move it outside `public/` (for example to `assets/blender/vendor/polyhaven/`)
and update `SRC` in `living_common.py` if the shipped size matters.

### Blender Studio Human Base Meshes v1.4.1 — `assets/blender/vendor/human-base-meshes/`

`human_base_meshes_bundle.blend` (Blender Studio, CC0 1.0,
https://studio.blender.org/training/human-base-meshes/). It provides the realistic male and female
base meshes at the level-0 cage. Eyes are merged in. These meshes are reposed procedurally by `L.Figure`
into the security diver (`security-post`), the manager (`manager-office`) and the cocooned man
(`cocoon-corpse`). The skinning, posing, clothing shells and materials are generated by the scripts.

### Fonts (Windows system fonts, used only to bake signage into textures)

`msyhbd.ttc` (Microsoft YaHei Bold), `bahnschrift.ttf`, `STXINGKA.TTF` (handwriting/chalk),
`segoeprb.ttf` (handwritten digits). Glyphs are rasterised into the decal atlases only; no font files
are redistributed. Before a commercial release, confirm the licence terms for embedding Microsoft
and SinoType glyph rasters in game textures, or switch to OFL fonts (for example Noto Sans SC or
LXGW WenKai).

## Creature GLBs — `living-creature-lumen.glb`, `living-creature-shade.glb`, `living-creature-blind.glb`

Generated headlessly by `tools/blender/build-living-creature-<type>.py` and the shared module
`tools/blender/build-living-creature-common.py` (Blender 5.1, `blender -b --factory-startup -P <script>`).
All inputs are procedural and no third-party asset is used. The pipeline:

- numpy blockout
- voxel remesh
- numpy noise sculpting on a high mesh of 0.5–1.1 M triangles
- Decimate to the low mesh
- seam-labelled angle-based UVs
- Cycles selected-to-active bakes (tangent normal, AO, albedo/roughness/curvature/emission from vertex attributes) into 2K/1K maps
- numpy-generated membrane textures (fins, curtain, frill)
- numpy-weighted armature with looping clips pushed to NLA tracks

Textures: albedo WebP q90 (alpha = tissue thinness for wrap/transmission), tangent normal WebP lossless,
ORM (R occlusion, G roughness, B metal = 0) as 1024 PNG so lossy chroma never bleeds roughness into occlusion;
fins/curtain/frill colour WebP. Teeth carry COLOR_0 (alpha = thinness) instead of a texture. Skin palette is
calibrated in linear albedo (dorsal brown 0.048, soot 0.017, belly 0.06, rot 0.13) for the recording camera's
exposure; roughness runs 0.18 (slime) – 0.95 (dry hide).

Each type also ships `living-creature-<type>.lod1.glb` (same skeleton and clips, no textures; LOD0 materials
are reused at runtime), decimated to ~34 % of LOD0:

| type | LOD0 tris | LOD0 size | LOD1 tris | LOD1 size |
|---|---|---|---|---|
| lumen | 33 449 | 4.53 MB | 11 633 | 0.43 MB |
| shade | 32 062 | 3.55 MB | 11 230 | 0.39 MB |
| blind | 32 851 | 4.04 MB | 11 225 | 0.40 MB |

Per-asset triangles, bounds, bones, clips and texture sizes are written next to each GLB in
`living-creature-<type>.json`. Bake sources are stored in
`assets/blender/living-gen/creature-<type>/` and the .blend files in `assets/blender/living-creature-<type>.blend`.

## Not used

No Sketchfab, Poly Pizza or AI-generated (`generate_3d`) models are used in these assets.
