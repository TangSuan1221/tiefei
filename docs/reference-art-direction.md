# 隔离舱视觉样板

## 范围

`/reference.html` 是可移动、可切换探照灯的实时 Three.js 隔离舱样板，不是参考图投影或视频背景。现有关卡共享新的程序化材质，并增加货箱红色绑带；样板的完整舱室布局尚未替换整个游戏关卡。

参考重点：冷青色狭窄舱室、黄色圆角舱门、松弛布帘、左侧器材架、前景白箱红带、右下近景灯具、有限视野与水中散射。不得以新增怪物实体破坏既定的“只能经声音和录像感知怪物”设定。

## 实现

- `reference-room.ts`：圆角实体、舱门多层内衬、紧固件、管线、器材架、织物和箱体；合并静态几何，保留碰撞边界。
- `reference-materials.ts`：可复现的程序化颜色、法线、粗糙度贴图；漆面、金属、橡胶、织物、地板分别配置。
- `reference-preview.ts`：相机惯性、简易碰撞、阴影、环境遮蔽、泛光、镜头暗角和色差、水中微粒。
- `reference-water.ts`：使用实际场景深度约束的近似单次散射，不是完整流体或多重散射模拟。
- 布帘为预定义变形叠加轻微运动，并非物理布料求解器。碰撞为包围盒，不是刚体物理。不可宣称这些已达到 AAA 物理标准。

## 操作与验证

WASD 移动，Q/E 升降，拖动观察，L 开关灯，P 暂停水流。`?still&clean` 固定动画时间并隐藏界面，供可复现截图；仍允许移动相机。

`node tools/reference-capture.mjs qa/deepsea/reference-pass-N.png --verify` 验证真实 WebGL、移动、灯光关闭和不同机位。采样 elapsed 是 CPU 渲染提交耗时，不代表端到端 GPU 帧率。

`tools/reference-compare.html` 提供同宽高比并排对比。独立审查记录在 `reference-visual-review.md`。第一次 A/B 隐藏出处，之后已揭示出处的逐轮审查不再称盲测。

## 质量边界

技术测试通过不等于视觉验收通过。当前仍需按审查记录完善真实感、构图、灯光分布、布帘形态及资产细节。保留迭代截图作为证据，不以“AAA”作为未经验证的完成标签。
