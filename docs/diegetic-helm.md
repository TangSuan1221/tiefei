# 实体驾驶台与曝光首帧

- 中央窗口不再绘制驾驶、摄影、机械臂按钮排，仅保留画面和仪器状态。
- 窗下是 Three.js 实体控制台。鼠标拖动左侧操纵杆：上推推进、下拉倒车、左右转向；松手回中，艇体仍按水阻减速。原键盘驾驶仍保留。
- 曝光、照明、回放、云台回中、制动、离港使用实体按键射线检测。机械臂的完整工作台保留在侧面设备。
- 曝光通过同步视图回调重绘当前舱外光学画面，固定为 PNG；不拍舱内仪表、不拍旧录像，不包含取景器读数。画面包含当前房间、船位、朝向、云台、变焦和灯光。曝光后移动不更新该卷图片。
- 视频提交使用 multipart `input_reference` PNG；模板重试携带同一图片，缓存包含图片指纹；缺少图片时不静默改成纯文本生成。
- 接口格式依据 https://docs.litellm.ai/docs/videos 的 reference-image 参数。此项目所用自定义 MiniMax 代理是否支持该 multipart 输入仍需要真实上游验证；本次视频开关关闭，没有付费生成。已有服务若拒绝图片，显示冲洗失败，不会偷换成另一处场景。
- 验证：30 项模拟回归通过；浏览器实测实体照明按键、操纵杆拖动、连续键盘驾驶、横竖屏与首帧冻结。首帧浏览器测试拦截视频网络请求，不会付费。
