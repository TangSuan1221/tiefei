# 《铁肺迷城》IRONLUNG MAZE — 游戏设计文档 v1.0

> 一句话定位：**《动物迷城》的系统深度 × 《铁肺》的幽闭盲感 × 《SOMA》的哲学恐怖**，
> 一场在会重组的沉没潜艇里、靠声呐与呼吸计数逃生的分支叙事 roguelite。

---

## 0. 电梯陈述

深潜器 **KYRIE-9** 属于一个叫「**静默教团**」的组织。它下潜到了海图上标注为空白的地方。
你在密封舱里醒来，耳机里只有自己的呼吸声。船外不是水。

你看不见任何东西——舷窗是黑的，电力只够点亮手边一尺。你唯一的感知手段是**声呐**：
按下按钮，一次脉冲，世界以回波的形式在你脑中画出一张图。

但脉冲会**发出声音**。而外面的东西，是靠听觉活着的。

## 1. 设计支柱（所有决策的裁决标准）

| # | 支柱 | 含义 | 反例（禁止） |
|---|------|------|-------------|
| P1 | **看不见才是恐怖** | 玩家绝大多数时间靠**声音与回波**理解世界，视觉是奢侈品 | 明亮的第三人称全景地图 |
| P2 | **氧气即时间即货币** | 所有行为都用同一种资源结算，每个选择都是机会成本 | 独立的"体力条""金币" |
| P3 | **系统会对玩家撒谎** | 低理智时 UI/地图/对话/存档提示**本身**变得不可信，且可被识破 | 只加滤镜和抖动 |
| P4 | **地图是活的** | 拓扑在玩家不观察时重连，但重连**有规律**、可被推理 | 纯随机、无法学习 |
| P5 | **每个选择都留疤** | 教团标记(Stigma)永久改变世界、怪物行为与结局 | 选项只改一句台词 |
| P6 | **死亡是叙事，不是惩罚** | 死→教团把你捞回→保留"知识"，世界重组 | 读档倒退 |

**苛刻判据**：任何提交的机制，如果不能明确指出它服务于上述哪一条支柱，就删掉。

## 2. 玩法 DNA 拆解

### 2.1 从《动物迷城》继承（并改造）

| 动物迷城 | 本作对应 | 改造要点 |
|---------|---------|---------|
| 行动点/日程 | **呼吸(Breath)** | 从"一天几格"变成"一口气几秒"，压迫感量级提升 |
| 城市格子探索 | **舱段图(Graph)** | 从欧氏网格变成可重连有向图 |
| 随机事件+选项 | **舱室事件** | 事件带 Stigma 后果，跨轮回记忆 |
| 回合制战斗 | **遭遇(Encounter)** | 从 HP 对拼变成"定位—认知—处置"三阶段 |
| 属性/装备搭配 | **改造与植入** | 每个增益都有生理代价 |
| 打工/经济循环 | **维生循环** | 制氧、发电、排水三条互相挤占的支线 |
| 多结局 | **8 结局 + 真结局链** | 由 Stigma × 知识 × 最终抉择决定 |
| Roguelite 轮回 | **复苏仪式** | 死亡被叙事化，元进度=知识而非数值 |

### 2.2 从《铁肺》继承（并加深）

- **完全的视觉剥夺**：铁肺只有一台相机；本作给你**声呐 + 一盏会耗电的灯 + 有限的舷窗**。
- **坐标即玩法**：铁肺让你手动对齐坐标；本作让你**手绘心智地图**——因为系统给的地图会骗你。
- **不可见的威胁**：你永远不会完整看到 THE LISTENER。只会看到它留下的**证据**。

### 2.3 本作独有

1. **Veracity Layer（真实性层）** — 见 §5
2. **Noise Budget（噪音预算）** — 见 §4.3
3. **非欧重织（Reweave）** — 见 §6.3
4. **认知系统（Cognition）** — 你对怪物的"了解度"是一种可积累的资源，了解它才能对付它

## 3. 核心循环

```
        ┌──────────────────────────────────────────┐
        │              感知 (PERCEIVE)              │
        │  声呐脉冲 / 贴门聆听 / 点亮手灯 / 读日志    │
        │   代价: 呼吸 + 噪音       收益: 信息        │
        └────────────────────┬─────────────────────┘
                             ↓
        ┌──────────────────────────────────────────┐
        │              推理 (DEDUCE)                │
        │  这张图是真的吗？那个回波是它还是幻觉？      │
        │  玩家在纸上/脑内建模 —— 游戏的真正战场       │
        └────────────────────┬─────────────────────┘
                             ↓
        ┌──────────────────────────────────────────┐
        │              行动 (COMMIT)                │
        │  移动 / 撬门 / 搜刮 / 交互 / 仪式 / 战斗    │
        │   代价: 呼吸 + 噪音 + Stigma               │
        └────────────────────┬─────────────────────┘
                             ↓
        ┌──────────────────────────────────────────┐
        │             后果 (CONSEQUENCE)            │
        │  地图重织 / 水位上升 / 它更接近了 / SAN 下降 │
        └────────────────────┬─────────────────────┘
                             └──→ 回到感知
```

**节奏**：一次"感知—推理—行动—后果"约 30–90 秒。一轮回（run）约 45–90 分钟。

## 4. 核心系统规格

### 4.1 呼吸与氧气（Agent A）

- 氧气储量以**呼吸数**计。初始 `oxygenMax = 900`（约 15 分钟静息）。
- 每个动作的基础成本见 `contract.ts` 的 `BREATH` 常量。
- **实际成本** = 基础 × `derived('breathCost')`，后者受：
  - 恐惧 fear：`1 + fear/100 × 1.2`（恐惧时最多多耗 120%）
  - CO2：`1 + co2/100 × 0.6`
  - 外伤 trauma：`1 + trauma/150`
  - 低温：体温 < 35°C 时每度 +8%
- **屏息（Hold Breath）**：主动动作，暂停氧耗但 CO2 每呼吸 +4，CO2 ≥ 80 时强制大喘气（巨大噪音）。
  > 这是本作最重要的**微观决策**：它把"资源管理"压缩进单个紧张瞬间。

### 4.2 理智（SAN）

- 0..100。下降源：目击异常、黑暗滞留、被注视、仪式、认知冲击。
- 上升源：光照、进食、确认现实（Reality Anchor 道具）、成功识破谎言（+debunk 奖励）。
- **SAN 不是血条**：它是 **Veracity Layer 的强度旋钮**。SAN 归零不死，而是进入
  **"完全共鸣"**状态——世界彻底变成主观的，此时开启一条专属的隐藏结局线。
  > 反套路：低 SAN 不是纯惩罚，而是通往某些内容的**唯一钥匙**。这是让玩家敢于冒险的设计。

### 4.3 噪音预算（Noise Budget）

- 每个房间有 `noise` 累计值与 `noiseThreshold`。
- 噪音随时间以 `-0.8/呼吸` 衰减，但**水中传播**——相邻房间获得 40% 溢出。
- 超阈值 → `listener-summoned`。Listener 不会立刻出现；它开始**朝你移动**，
  沿途留下可被声呐探测到的**扰动**。玩家有 8–20 个呼吸的窗口逃离或隐藏。
- 噪音源示例：走路 1 / 跑步 6 / 开门 3 / 撬门 12 / 声呐 9 / 开枪 40 / 尖叫 60 / 大喘气 25

### 4.4 声呐（Agent B）

- 三种模式，构成一个**风险—信息**的三角：
  | 模式 | 呼吸 | 噪音 | 半径 | 保真度 |
  |------|-----|------|------|--------|
  | 被动聆听 Passive | 2 | 0 | 1 | 0.35 |
  | 短脉冲 Chirp | 4 | 9 | 3 | 0.8 |
  | 全功率 Boom | 7 | 28 | 7 | 0.98 |
- **保真度** 决定假房间(artifact)混入的概率：`pArtifact = (1-fidelity) × (1 + corruption×2)`
- 声呐会返回 **anomalies**（回波异常）。玩家看不出那是怪、是尸体、还是自己的回声。

### 4.5 遭遇（Agent D）

三阶段，不是回合制砍怪：

1. **STALK（潜行相）**：它知道有东西，但不知道在哪。玩家的每个动作都在给它信息。
   可用动作：屏息、缓慢移动、扔东西制造假声源、熄灯、涂抹尸油掩盖气味。
2. **CONTACT（接触相）**：它锁定了你。进入部位定向的攻防。
   - 攻击**部位**而非整体。摧毁"耳器"让它失去听觉，摧毁"腱"让它变慢。
   - 每次攻击都有噪音，会吸引**别的东西**。
3. **PANIC（失控相）**：玩家 fear ≥ 85 时强制进入。行动选项被**随机替换**，
   部分按键失灵，这是机制层面的恐慌，不是演出。

**认知（Cognition）**：初见时敌人名字显示为 `???`，描述是错的。
通过观察、尸检、档案，cognition 上升，才解锁针对性的动作与正确的部位图。
> 这让"了解怪物"变成一种跨轮回的核心进度，直接对应支柱 P6。

### 4.6 物品与制作

- 背包有**重量**与**响度**：金属物品移动时会响。
- 关键制作链：
  - 制氧：`碱石灰 + 呼吸器` → 延长氧气
  - 照明：`镁条 + 引信` → 一次性强光（巨大噪音，但能永久揭示一片区域）
  - 静默：`油脂 + 布` → 消音包裹，降低移动噪音
  - 锚定：`镜子 + 照片 + 血` → Reality Anchor，回复 SAN 但留下 Stigma

## 5. Veracity Layer（真实性层）— 本作的招牌机制

**这是评审时最应该被苛刻检验的部分。**

系统在 `corruption = f(SAN, infection, depth, stigma.listening)` 驱动下，
对**玩家感知到的一切**进行污染。污染是**分层**的：

| 层级 | corruption 阈值 | 表现 |
|------|----------------|------|
| L0 清明 | < 0.15 | 无 |
| L1 漂移 | 0.15 | HUD 数字轻微跳动（±2），偶发脚步声 |
| L2 错认 | 0.30 | 物品名称偶尔变成 `falseName`；地图出现一个不存在的房间 |
| L3 篡改 | 0.50 | NPC 对话被替换成 `corruptedText`；声呐返回伪影 |
| L4 伪造 | 0.70 | 出现假 NPC、假存档提示、假门；日志内容自己改写 |
| L5 共鸣 | 0.88 | 真假反转：只有"幻觉房间"里的东西是真的。开启隐藏线 |

**关键设计：谎言必须可被识破（Tell）。**
每个 `Lie` 都带一个 `tell` 字段——一条玩家可以观察到的破绽：

- 假房间：声呐两次脉冲的回波延迟不一致
- 假 NPC：它的呼吸声与你的**完全同步**
- 假存档提示：时间戳是未来的
- 假门：门把手上没有你自己留下的划痕（玩家可主动"做标记"）

玩家主动 `debunk` 成功 → SAN +8，`lucidity` 永久 +1（跨轮回）。
**这把恐怖从"承受"变成了"博弈"**，是本作对标 TGA 级设计的核心论据。

## 6. 世界与地图（Agent B）

### 6.1 结构

KYRIE-9 共 **5 层甲板**，深度从 -340 m 到 -2,100 m（船体已断裂并卡在海沟壁上，所以"下层"其实更深）：

| 甲板 | 名称 | 主题 | 基调 |
|------|------|------|------|
| D1 | 生活层 Habitation | 铺位、食堂、医务室 | 人味残留，最"正常"，教你规则 |
| D2 | 机械层 Machinery | 引擎、配电、压载 | 解谜密度最高，噪音最大 |
| D3 | 指挥层 Command | 舰桥、声呐室、档案 | 信息层，真相在这里 |
| D4 | 圣所层 Sanctum | 礼拜堂、圣物室、观测窗 | 教团层，仪式与抉择 |
| D5 | 月池层 Moonpool | 通往外面 | 终局，非欧最强 |

### 6.2 生成算法要求

- 不是 BSP 矩形房。用 **加权图生长 + 约束求解**：
  1. 放置必需舱段（每层的锚点房间）
  2. 用"走廊脊柱 + 分支"连接，保证**至少两条**通往下一层的路径
  3. 注入可选内容：秘密舱、淹水区、爬行管道（爬行管道是**噪音最低但 SAN 消耗最高**的路径）
  4. 用**可达性求解器**验证：在最坏情况下（所有可选门锁死）仍能通关
- **必须可通关性验证**：生成后跑一遍求解器，失败则重生成。不允许"运气不好卡死"。

### 6.3 重织（Reweave）

- 触发：玩家离开视野 + 深度压力 + 累计 Stigma
- 规则（**必须可被玩家学习**）：
  - 只有标记为 `unstable` 的门会重连
  - 重连**保持连通性**（不会把你困死）
  - 重连遵循"**它把你往圣所层推**"的倾向——这是它的意志，也是玩家能利用的规律
  - 玩家在门上"做标记"可以**检测**重织是否发生

### 6.4 惊喜地图清单（必须实现）

- **镜像舱**：一个与你刚走过的房间完全对称的房间，包括你留下的痕迹——但痕迹是反的
- **莫比乌斯走廊**：往前走四次回到起点，但每次回来房间都少一件东西
- **零号舱**：不存在于任何图纸上的房间，只能在 SAN < 20 时被声呐扫到
- **淹没的圣堂**：需要屏息通过，全程无法使用声呐（水中声呐会暴露你）
- **你自己的舱室**：里面有一具穿着你衣服的尸体，日志是你还没写的

## 7. 叙事（Agent C）

### 7.1 真相层级（玩家可能只挖到第 1 层就通关）

1. **表层**：KYRIE-9 是科考船，发生了事故，你要逃。
2. **中层**：它是教团的"聆听装置"。全员自愿下潜，为了听见"那个声音"。
3. **深层**：声音是真的。它一直在，从海里，从你的血里。教团没疯。
4. **真层**：你不是幸存者。你是第 **N** 个被打捞、重置、再放回去的样本。
   船在重组是因为**它在为你调整**——它在教你，像训练一只动物走迷宫。
5. **底层**：迷宫不是给你走的。你走过的路径本身，就是在**书写**某种东西。
   每一轮回，你的路线在海床上刻下一笔。八个结局是八个笔画。

### 7.2 关键 NPC（全部不可完全信任）

| ID | 名字 | 身份 | 核心张力 |
|----|------|------|---------|
| `vance` | 万斯 | 无线电里的声音，自称救援 | 他给的坐标越来越准——因为他在船上 |
| `mother` | 母亲 | 潜艇 AI，声音是你母亲的 | 它是被录下来的，还是被做出来的 |
| `dorn` | 多恩 | 大副，活着，被绑在椅子上 | 是他绑的自己，还是别人绑的 |
| `the-choir` | 唱诗班 | 六具还在唱歌的尸体 | 他们唱的是你的名字 |
| `pelle` | 佩勒 | 一个小孩的声音，在管道里 | 船员名单上没有小孩 |
| `yourself` | 你自己 | 第 N-1 个你 | 他留下的日志在预言你的行动 |

### 7.3 八个结局

| ID | 名称 | rank | 核心条件 |
|----|------|------|---------|
| `end.surface` | 浮出水面 | good | 逃出 + SAN>50 + 未完成任何仪式 |
| `end.silence` | 缄默 | bittersweet | 逃出 + stigma.silence 最高 + 焊死月池 |
| `end.congregation` | 入会 | bad | 完成三个仪式 + stigma.listening ≥ 5 |
| `end.drowned` | 溺者 | bad | 主动淹没自己 |
| `end.iron` | 铁肺 | bittersweet | 把自己接入船体维生系统 |
| `end.apostate` | 叛教者 | good | 摧毁圣物 + 逃出 |
| `end.zero` | 零号 | secret | 进入零号舱 + 知晓真层 |
| `end.author` | 书写者 | true | 跨 ≥4 轮回集齐全部知识节点 + 在月池做出最终抉择 |

### 7.4 叙事技术要求

- 全部对白**数据驱动**（`NarrativeNode`），可被校验器静态检查悬空引用
- 每个重要节点都要有 `corruptedText` 变体（低 SAN 时的版本）
- 对白遵循**契诃夫式**：重要的话说一半，真正的信息在人物**不说**的地方
- 禁止"日志倾倒"：任何超过 120 字的独白必须拆成可被打断的段落

## 8. 表现（Agent E）

### 8.1 视觉基调

- **调色板**：不用"恐怖游戏绿"。用**铁锈橙 (#c4632a) / 深渊蓝黑 (#060a10) / 骨白 (#d8d2c4) / 警示血红 (#8e1620)**
- 主体渲染：Canvas2D 绘制"声呐屏 + 舱内剖面"双层视图
- 后处理：WebGL2 多通道 —— 桶形畸变 → 色差 → 泛光 → 胶片颗粒 → 扫描线 → 晕影 → CO2 隧道视野
- **呼吸驱动的画面起伏**：整个画面随玩家呼吸节律做 ±0.6% 的缩放与亮度波动。这是最便宜也最有效的沉浸感来源。

### 8.2 音频（全程序化，无外部素材）

- WebAudio 合成：
  - **心跳**：两个带包络的低频正弦 + 噪声瞬态，BPM 跟随 fear
  - **呼吸**：滤波白噪声 + 共振峰，吸气/呼气不对称
  - **船体应力**：低频金属共鸣，深度越深频率越低、越密
  - **声呐**：啁啾脉冲 + 按房间距离计算的多抽头延迟回波（真实空间感来自这里）
  - **耳鸣**：低 SAN 时的 4–8 kHz 纯音，会随时间微微滑音
- **动态混音**：屏息时全局低通滤波 + 心跳突出，这是"生理沉浸"的关键

### 8.3 UI 原则

- HUD 不是浮层，是**面罩内壁的投影**：有曲率、有反光、有划痕、会起雾
- 氧气不用数字条，用**压力表指针**（指针会抖）
- 低 SAN 时 HUD 自己会撒谎，且**没有任何提示**

## 9. 内容体量目标（AAA 丰富度判据）

| 维度 | 最低门槛 | 目标 |
|------|---------|------|
| 房间原型 | 20 | 20 ✔（见 `RoomArchetype`）|
| 实际可生成房间变体 | 60 | 100+ |
| 叙事节点 | 150 | 300+ |
| 带条件的分支选项 | 250 | 500+ |
| 结局 | 8 | 8 + 变体 |
