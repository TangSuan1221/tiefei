# 状态驱动录像模板 v3

组合顺序：首帧空间约束 → 当前事件 → 当前房间 → 灯光与曝光 → 镜头时序 → 单一主体 → 画质与禁止项。

- 地点：读取实际房间和摄影机姿态；首帧优先，不写死气闸、矿厅、远门或 GH 编号。有当前地点时，不叠加关卡总场景及预设巡游运镜。
- 平静：使用固定曝光快照中的随机普通生物，允许空景，不重新随机。
- 异常／追踪：未辨认时表现具体痕迹；已辨认时允许对应主体。
- 撞击：实体攻击者必须作为唯一主角，至少可辨认两秒；排除普通鱼群、无实体描述、剧情编号和抽象符号的竞争。0–1秒建立原场景，1–3秒靠近，3–4秒单次撞击，4–5秒余震。不能提前生成死亡或已破舱结局。
- 事后：只表现现场残留，不重新发起袭击。
- 关灯：不凭空开启探照灯；允许感光增益保留主体中间调，实时探索仍保持幽暗。
- 无实体的自然遭遇保留原设定；GM「怪物入侵」改用实体幕皮，专用于撞击录像测试。

模板是模型请求，不是输出保证。单元测试检验冲突与地点替换；此次未进行收费视频重生成或艺术质量验收。
