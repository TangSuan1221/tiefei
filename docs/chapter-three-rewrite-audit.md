# 第三章重写审查 · 2026-09-30

对象：`docs/story-split-route-2026-09-30.md` 第三章及第四章入口、选择回收表。本文是本次逐项设计审查记录，不是独立玩家测试或新关卡实机验收。

重写前读项目规范，并检索 MET-025 / MET-030。重写后检查了时间顺序、四条威胁路线组合、资源支线、摄影时序、会合位置与第四章入口后果。将本次要求新增为 MET-031，以后每次重写都要留下对应审查记录。

## 本次改变

旧第三章由记录、会合、袖口异常组成。新第三章有四个主要遭遇：调查实验室警告与破口；危险补给；跟随者与撤退；进水与路线选择。会合是独立喘息段，章末袖口是前述结果片的叙事回收，二者不计主要遭遇。

压力次序：不知警告对象 → 看清非人的肢体 → 想拿资源却不能直接伸臂 → 与同伴会合 → 得知当年的求助被忽视 → 同伴报告艇后移动 → 先撤到隔离后才看见刚才的距离 → 进水逼迫放弃会合点 → 回片使玩家开始怀疑同伴。没有强制玩家留在危险处等待网络生成，也不把喘息后必定扑脸作为唯一节奏。

## 审查时发现并改掉的问题

1. 初稿把追逐写成必发事件，会使先前封闭水道的选择失效。改为四种组合：上层水道开/关、本层破口封闭/未封闭；两处都封闭，威胁留在隔断外，不能同样贴艇出现。
2. 清洁海水与已污染水都进入第四层时，原后文统称污染。改为第四章原状、进水、带组织进水三种抵达情况，关门不擦除已流入部分。
3. 为拍跟随者而留在原地等片不符合摄影时序与生存常识。改为可直接撤离；选择取证则曝光完成后撤入实体隔离泊位，再读片。该位置与曝光撤退时间仍需制作验证。
4. 会合和袖口揭露不再充作完整摄影遭遇。箱子是可选资源，不能把所有路线的通关依赖放在危险箱子里。
5. 隔断关闭不自动把组织变没。取箱只有在结果片确认物理隔离且取物位可用时成立，否则放弃并走已知外路。
6. 尼科的旧广播、万斯的证词、艾里亚斯找到的记录与玩家当下影像分开，不用旧广播认证任何人还活着。

第四章抵达：下层门始终关→原状；下层门开且此前无污染→进水；下层门开且此前污染→带组织进水。后两项即使复关也保留结果。污染有无与门是否曾开不能混为同一个布尔量。

任何“补拍无效、未见隔离成功”的状态都不授予取箱或回头许可；可返回安全机位、放弃可选箱子或走外路。不能以表格存在代替这些恢复路线的实际制作。
