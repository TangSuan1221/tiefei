## VR-101 先检索规则与外观，再组装镜头

状态：IMPLEMENTED / REQUIRED / GAP。关键词：prompt 标准 艾里亚斯 怪物 外观 声纳 断桥 NS-001 NS-002。

复用 `tools/video-prompt-rag.mjs` 的白名单、BM25检索、来源指纹和过期检查。这是本地词法检索与确定性组装，不是外部向量服务。检索用于找规则和素材；运行时按sceneId+choiceId精确取回镜头，不用相似度代替分支裁决。

网页与命令行共用 `src/narrative-lab/prompt-library.json` 和 `src/narrative-lab/prompt-composer.ts`。每条镜头必须包括主体数量、外观档案、空间遮挡、机位、光源、分段动作、声音、结束状态、原始结果匹配值及来源。缺条目、缺外观或原文变化时输出GAP，不能回退为小说段落。

模型正文仅包含英文镜头指令，来源、中文解释和剧情原文留在元数据。姓名不是外观，必须写材质、衣着、身体轮廓和固定辨识点；未定稿面貌不得擅自确定。艾里亚斯采用现有1.73m潜水员模型、暗色服装、棕色帆布、赭色头盔与暗面罩；怪物按VR-110深海克系文字档案（`src/pod/content/video-creatures.ts`）：港区生物为半透明受压皮肤、鳍膜蹼指、鳃裂、无腿拖曳下身、平静下垂面部，悬浮滑行不爬行；怪物全部由视频生成，参考帧不含生物模型；不解释生物来源。

叙事测试配置10秒、16:9、连续镜头、最长3600字符；旧主游戏PT模板仍是独立5秒/2200字符配置。长不等于好：主体→外观→空间→机位→光源→时间动作→声音→结束状态→简短画质限制。稳定结果只加轻微姿态和水流，不补演先前操作。

NS-001至NS-006已按当前因果分支更新：灯光引诱失败，声纳把生物引到艇旁；这两条只出镜怪物，艾里亚斯在掩体内不可见，不注入其外观。错误报告结果保留伤腿；隔离、伤者安置与补救只呈现已发生的稳定结果。任何人物只在现有开口内可见，不透墙增加机位。旧截图“钢筋缠住/已经握杆”不再作为当前结果。

有实际曝光参考图时锁定其几何、角色和遮挡。无图时左右构图仅为文生测试提案，不是已测摄影机位。文本不能保证跨片一致性，仍须参考图和生成后审片。

## VR-102 命令、覆盖与验收

状态：IMPLEMENTED / GAP。关键词：compose-branch query check 覆盖 检查。

```powershell
node tools/video-prompt-rag.mjs build
node tools/video-prompt-rag.mjs query "艾里亚斯 怪物 外观 声纳 断桥" --top 3
node tools/video-prompt-rag.mjs compose-branch L0-01 lure-noise

```

当前启用第一节点首次侦察片与六个最新因果分支，其余明确显示GAP并等待逐镜头补齐。工作区剧情在本次实现过程中发生修订，镜头已按最新首节点结果重审；不能批量翻译全篇后宣称正典合规。录像卡片直接显示中文镜头内容和完整英文Prompt，“视频提示词”标签显示已显影片匣的历史快照。

检查覆盖全部启用条目、外观缺失、结果变更、非光学、未选择分支、存档恢复及网页复制；检查通过只证明组装契约，不证明实际视频效果。主游戏接口未接入本叙事测试镜头库，旧PT模板也不因本次接线变成当前实机证据。

## VR-103 侦察片与结果片必须共用拍摄入口

状态：IMPLEMENTED / GAP。关键词：首次侦察 scout 曝光 快照 录像卡片 中文镜头 Prompt。

2026-10-11 用户截图指出实际测试的首卷仍是简短剧情摘要。此前只接入行动分支导出，未接首次侦察，是集成遗漏。现由 `src/narrative-lab/engine.ts` 的shoot在曝光时调用组装器，侦察使用@scout，结果使用当次choiceId，保存中文storyboard与英文prompt。显影前不在界面公开，不提前授予知识。显影后在同一录像卡片直接显示，复制按钮只复制完整英文正文。

NS-000将原“门未落下不能算隔离”改为可见的升起格栅、开放入口和仓外生物；将“独立配电”限定为可见的闭合柜壳与控制盒，不从外壳推断通电状态。镜头交代前后景、断桥上下关系、长肢三指外观、遮挡、低照度和时间动作；艾里亚斯被不透明门板遮住，不注入人物外观或画出其身体。潜艇驾驶员也不出镜。

中文镜头说明与模型指令均来自同一条目；原剧情摘要仍作为状态机授权数据，不再冒充成可直接生成视频的正文。未建镜头显示GAP，旧存档未保存prompt时提示重拍，绝不用新库静默重写旧片。保存的提示词仅作展示，不参与证据或事实授权；格式校验拒绝非法快照。

检查：`tools/narrative-scout-prompt-check.ts` 覆盖曝光锁定、改库后旧片不变、结果片后旧片不变、恢复一致、缺条目、改变现场文本、非光学、旧存档与非法快照；`tools/narrative-video-prompts-browser-check.mjs` 直接从首卷侦察验证可见性、复制、结果片与历史片，不再只测先行动后切标签。5秒曝光/12秒显影仍是状态机时序，10秒是导出文生测试时长，不冒称已生成或接入主游戏录像。
