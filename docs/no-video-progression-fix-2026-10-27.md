# 无视频模式分析台推进修复

2026-10-27。范围：主游戏第一、二关无视频诊断入口。

问题：任务播放器在无视频模式停止回片，空片盒使普通分析按钮禁用；现场底片普通分析也可能等待正式媒体。已有文字诊断口令可推进，但没有对应分析台操作，造成操作路径中断。

IMPLEMENTED：分析台增加“核验任务”（8），空片盒可用；无视频模式的分析键（3）改为“诊断底片”，调用已有诊断核验逻辑。两者要求分析台、供电、显式无视频模式和第一/二关。第二关诊断底片补充当前关、显影完成及曝光状态检查。关闭模式后撤销入口，沿用诊断进度暂停和禁止正式存档规则。无视频空片盒不再显示重试下载按钮。

验证：TypeScript 检查；harbor-simple-flow-check、living-survey-check通过。no-video-lab-controls-check 浏览器测试两关空档案任务核验、空底片拒绝、模式关闭拒绝；使用诊断工位设置与实际控制分发，不是人工键鼠全程游玩；两关无浏览器异常、无 API 请求。

GAP：未验证完整驾驶通关、第三关媒体流程和真实生成视频。未修改剧情、关卡尺寸、声纳规则或碰撞通道。MET-001/030/031/034的进度与验证边界保持，其他MET本轮不涉及改写。既有 RAG query/check 在修改前即因 living-deck-site、living-survey-fixtures、living-world 源文件过期失败；本轮未修改规范，也未将重建索引冒充语义审核通过。

## 修订：剧情视频不核验（同日用户指示）

用户：“除了怪物视频，剧情视频不需要核验和诊断底片。”

IMPLEMENTED：第一、二关艾里亚斯任务视频（剧情视频）不再经分析台核验。正式模式下，当前阶段的任务录像下载为可播放生成视频即自动登记、推进并显示台词，录像仍留档可播放；首关开场呼叫仍须接听并播完（原有逻辑）。无视频模式下，任务到达阶段即以带GM标注的文字自动推进，仍将本局标为测试局、禁写正式存档。撤除分析台“核验任务”（8）；“诊断底片”（3）只用于玩家自己拍的现场底片（怪物摄影）。对已登记的剧情录像再按分析只提示“无需核验”，不扣电、不改进度。相关目标、提示与GM说明改为“自动登记”。

未改：怪物摄影的正式核验与无视频诊断规则；第二关说明牌底片（非怪物，但属于读取说明的玩家摄影）仍走底片诊断，否则无视频模式无法读取；第三关 abyssal 媒体管线未改动。

验证与边界见下方本轮记录；检查脚本 no-video-lab-controls-check 改为断言无“核验任务”控件、tick 后自动推进；其余用“诊断核验任务”推进的浏览器脚本改为 tick 推进。
