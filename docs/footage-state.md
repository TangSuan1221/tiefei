# 游戏状态驱动录像

快门开启时锁定本卷的关卡、空间、光照、噪音、推进档位、船体、理智、怪物遭遇编号和拍摄次数。曝光结束才提交计数；中途离开导致的废片不提升重复等级。显影、回放和异步回调均读取这份快照，不读取此刻正在追踪的怪物。

| 状态模板 | 判定 | 录像重点 |
| --- | --- | --- |
| 平静探索 | 无活动威胁，警觉低于本关阈值的一半 | 普通深海生物、海雪、设施环境 |
| 异常初现 | 警觉达到一半，或怪物正在调查 | 必定出现逆流、空水缺口等异常证据 |
| 持续追踪 | 猎手进入跟踪阶段 | 痕迹变近，逐步出现画外阴影、镜头附近的压痕 |
| 攻击前兆 | 猎手处于独立攻击预警窗口 | 舱壁受压、镜头护罩出现痕迹；不虚构已经死亡或破舱 |
| 事后余波 | 遭遇刚结束，仍在恢复期 | 留下旧痕迹和沉降的淤泥，不继续升级追击 |

平静状态在首关没有随机异常；之后每关间接异常概率为 3%、4%、5%、6%、7%、8%。其余抽样以普通海洋生物和环境为主。随机使用独立种子流，每卷只抽一次，回放不会重掷。低理智只改变干扰强度，不能暗中把平静录像变成怪物合集。

## 重复与证据

同一活动遭遇的每次有效曝光递增记录序号。强度由状态基础值、关卡进度和重复次数决定，最高 6 级：逆流空缺 → 连续凹痕 → 画外逆行阴影 → 痕迹逼近镜头 → 不可能的反射 → 密封玻璃内侧压痕。后期可能从更高强度起步。状态升级仍沿用同一遭遇序号；新遭遇重新计数。

异常期间保证的是可辨认的证据，不是保证看清怪物身体。快门开启时瞄准正确且具备光学条件，才记录可识别的物种。未对准或关灯仍有异常痕迹；空回声保持无实体设定。录像不会改变实时镜头不可见怪物的规则。

五秒模板：0–1 秒建立环境，1–4 秒展示选定主体或证据变化，4–5 秒留下可读结果。提示词只包含本卷选中的生物，不再枚举整个关卡的沉睡怪物。机关周期、通行薄弱点等必要几何信息仍保留。

## 缓存与服务回落

主提示词和不含实体的备用提示词共同构成内容缓存键；不再用关卡 ID 作为缓存键。内存缓存最多 12 卷，浏览器任务记录最多 24 条；缓存同时保存“未恢复怪物身体”信息，命中缓存不能错误识别怪物。重复播放当前录像不产生请求，新拍摄可能产生新的付费生成任务；默认视频开关保持原状。

备用模板保留同一状态、重复强度和必要痕迹。网络失败、无视频服务或显影超时时使用机载录像。离线画面及远端回放附加本卷固定的证据层和字幕，确保第三方模型漏画时关键玩法线索仍可读。程序化证据是简化视觉，不等同于最终视频素材的美术质量。

本卷主/备用提示词、状态和缓存身份保存在磁带记录中；分析台输出拍摄状态及痕迹。在 GM 无视频模式下可直接检查本卷提示词，无需调用收费服务。
