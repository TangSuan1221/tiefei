# Panacea：剧情制作与因果资料

这是与小说正文分开的制作资料。当前正典为用户本轮Panacea设定；旧“尼科—莱娜—感染逃逸”稿件仅是历史版本，不与本稿拼接。当前阅读和分支仍是设计稿，尚未迁移旧状态机或3D游戏。

## 采用的解释与待定项

- Alex暂统一为艾里亚斯，不另造角色；Vera统一中文维拉。Delroy Campbell为德尔罗伊·坎贝尔。
- 五关编号0、-1、-2、-3、-4；第三关为第三个可玩层，即-2层，承接先前中途会合要求。德尔罗伊精英遭遇在-3，章鱼最终遭遇在-4。
- 主存容量按承载关键物资的主存储舱理解，不写成因计算机内存小而必须丢录像。若后续决定真指数字存储，需另立机制，不能删改已取得证据。
- Panacea是深海共生介质，不是病毒、声波诅咒或具有杀戮目的的病原体。治疗需要真实接触/处理与适应过程，听声音、碰普通海水不使人自动转化。
- 接受者身体逐渐免于损伤、高压、缺氧及饥饿，自我边界逐渐消失；绝对平静和愿意融入是其主观体验。未充分知情的早期治疗、经济压力和替别人作决定仍构成悲剧，不能由作者替所有人宣布同意。
- 艾里亚斯保持人形是个人特殊适应现象；短期检查正常解释了为何未被识别，不发明已证实的基因定律。他并非完整保留原人格，对“陪伴”的理解已经改变。
- 章鱼多年被饲养，逐渐形成学习、依恋和主动行动；六周内与老人身上的介质接触，加速成长。不是事故当天忽然从幼体变Boss。父子称谓是故事关系，不宣称人类遗传亲子。
- 原稿“怪物为食物诱骗”被最新设定替换为主动邀请、错误救护与取消他人拒绝权；伤害可以发生，但不把介质写成恶意驱使捕食。

## 事故时间线

| 时间阶段 | 事件 | 可调查材料 |
| --- | --- | --- |
| 多年前 | 资源耗尽、生物灭绝，科研资金由太空转向深海；德尔罗伊在能源层工作并饲养章鱼 | 序章简报、旧日常影像 |
| 商业化之前 | 维拉发现介质、形成治疗方法；公司推动短周期临床。艾里亚斯等受伤员工是早期受试者 | 检查影像、试验批准记录 |
| 随后数月 | 疗效出众，贵宾疗养开业；供应优先、员工和家属的治疗资格排队。德尔罗伊孙子的申请早于开业 | 仓库影像、申请与批注、供给记录 |
| 事故前六周起 | 德尔罗伊私取介质验证自身旧伤，期待为孙子申请；逐渐不再渴望上岸。章鱼接触介质后成长加快 | 缺药记录、私人录音、连续日常影像 |
| 事故初起 | 德尔罗伊开启检修通路接章鱼；章鱼保护老人时压坏未全开的隔断；进水扩展 | 能源层旧监控、门控与报警时间 |
| 事故扩大 | 公司要求维持贵宾供能，停工延误；部分受治疗者主动入水、打开通水门，普通工人被困 | 公司原始指令、后续当前观察和声音 |
| 首关之前 | 已变化的艾里亚斯把本可撤离的弟弟叫回来，拒不开返回门；弟弟未经介质治疗，溺亡。随后艾里亚斯被另一变化者逼到墙角 | 港口旧监控及通话；第一卷尸体位置；后期本人承认 |
| 玩家到达 | 真正救下被困艾里亚斯，断桥分路；新坍塌堵退路；逐层调查并寻找电梯 | 玩家当前曝光原片与日志 |

尸体身份仅第四章揭示；首章不安排目光闪避、说谎特写、身体异常等暗示。尸体存在本身是用户新要求，对“首章无身份线索”的限定例外；死亡责任不提前泄露。首章救援仍然真实。

## 每关的调查与摄影节点

采用Flow Fragment / Condition / Instruction的制作结构；下列ID是文档标记，不是已经导入Articy的工程。节点必须先取得对应证据再开放决策，旧录像不可改写。

| 层 | 节点 | 线索→侦察→决定→结果→继续 | 调查推进 |
| --- | --- | --- | --- |
| 0 | P0-01 | 调谐求救→拍门梁→艾里亚斯本侧落门→确认门体与平台→去楼梯 | 找到活人和未识别尸体，记录异常先于新坍塌 |
| 0 | P0-02 | 内侧报门号→拍封闭水道→NPC开门→半开复核与全开结果→通行 | 内外合作建立信任，不推断身份 |
| 0 | P0-03 | 碰撞声→箱旁摆动门板→NPC闭上游通水门→复拍稳定→取箱收臂复拍 | 资源管理嵌入路程，不新增机械臂目标 |
| -1 | P1-01 | 疗养呼叫→拍形变但平静的患者→保留隔离→拍门和患者→绕行 | 修复宣传与身体变化冲突 |
| -1 | P1-02 | 仓号→拍空员工仓/满贵宾仓→取用或留存→物资口和回收结果→补给或下一站 | 阶层分配与孙子排队，区别资源事实和主观愤怒 |
| -1 | P1-03 | 相同声音冲突→拍固定通话器的拟声组织→隔断→拍声源与闭门→另路 | 声音不能认证个体；不存在凭空无线电 |
| -2 | P2-01 | 医疗证词→拍当前患者并对照旧检查→换位看连接→保留/开启近路并拍结果→绕行或污染路线 | 自我边界变化与试验周期缺失 |
| -2 | P2-02 | 患者说回家→拍手在通水控制处→通知同伴走高处→复拍同伴与隔断→新路会合 | 主动入水与事故被淹区分 |
| -2 | P2-03 | 同伴报艇后轮廓→可拍或直接退→NPC闭维修泊位→结果确认→走后出口 | 伸手救护可构成致命威胁；袖口是末段证据，不另充遭遇 |
| -3 | P3-01 | 袖口疑点→当前影像与旧检查→质问并调港口原始记录→决定断/有限合作 | 兄弟死亡与非正常伦理判断，不因人形视为未变化 |
| -3 | P3-02 | 两下敲击→拍老人和机械性工作行为→在伸手压艇前退入隔断→结果核验→修复后远路 | 精英敌人目标是错误修护，不是吃人 |
| -3 | P3-03 | 电梯失电→拍维护台/敞开维护门→真实交班请求或应急供电→电力与门位结果→下潜 | 保留职业习惯；选择有等待与供电状态差异 |
| -4 | P4-01 | 父子节奏→两角度拍腕足遮挡/托艇→退回掩体→拍当前阻挡→选策略 | 章鱼要把人送给父亲，不是随机冲撞 |
| -4 | P4-02 | 能源层真实声音→接通到下层或改绕路→分阶段复拍腕足让路→闭隔断并拍结果→通过 | 父子关系改变最终遭遇，不用假孙子录音 |
| -4 | P4-03 | 维拉报接驳/同伴位置→拍三段隔离→决定同行/留置→再拍人物抵达和门位→接驳排水离艇 | 当事人选择与他人安全并存 |

这些节点有的尚缺完整可玩异常/补救分支，尤其P3-01主要是证据调查，不当作已满足三次完整摄影动作循环。完整配额、净空、演出与资源实测仍为GAP；表格不是验收结论。

## 能力与制作边界

现有基础相机、驾驶、箱子回收、补给基础可复用；NPC移动门控、故障门反复操作、物资口、患者放水、德尔罗伊、章鱼、接驳排水、电梯及Panacea结局演出待制作。用户已明确要求的角色/Boss仍需模型、动画、声音、遮挡与状态保存预算，不将文字当零成本资产。

主游戏已有导航声纳与旧ping被动档，但旧被动档仍可能产生近距contact，不等同本次“被动不扫描障碍、只收远方声音”的新定义。坐标输入、调频解调水声求救、固定节点转发、父子声音路由、完整日志触发均需实现核验。这里按新设计写故事，没有修改声纳代码。

新增场景只使用基础艇外相机可见窗面和真实换位；不开远摄、穿墙、隔桥机械臂或玩家搬人。精英与最终Boss采用识别行为、避险、隔离和路线选择，不默认游戏拥有枪炮。维修通过既有补给/服务设计表达，不增加机械臂抓墙修船。

初次体验预算：序章4分钟；0层9；-1层10；-2层12；-3层13；-4层12，共60分钟设计目标。包括读片、驾驶和选择的目标分配，不是实测证据。任何网络延迟不能成为必死倒计时。
