# 舷窗操作台参考图美术重构 · 2026-11-03

状态：IMPLEMENTED（Three.js模型与材质）/ GAP（参考图匹配、商业品质须以最终图像判断）。

本轮仅修改驾驶舱操作台视觉。用户提供的深绿色磨损金属操作台截图为唯一美术构图参考。未修改剧情、关卡、航行物理、声纳、摄影流程、存档或交互动作语义。未使用第三方下载资源；纹理由确定性程序生成。

实现文件：`src/pod/view/cabin-helm.ts`、`src/pod/view/cabin-helm-materials.ts`。保留既有未提交工作；本记录不把工作区其他改动算作本轮成果。

## 实现与对照

- 三片军绿色金属面板；球头摇杆、橡胶风琴套、纵向档位滑轨、四枚方键。
- 红色制动帽、护环与褪色黄黑底圈；齿纹照明旋钮、琥珀灯、方形曝光键及圆形机械臂键。
- 既有机械臂收回功能仍有独立实体小键，属于保留游戏内容所需的参考图差异。
- 金属/涂漆/橡胶分材质；颜色、粗糙度、金属度与凹凸贴图关联；局部环境反射仅绑定操作台，不影响艇外摄影照明。
- 中文铭牌按实际物理宽高比生成，避免字形压扁；纹理登记到既有释放列表。

独立审查工具：`tools/helm-reference-review.mjs`。截图在 `qa/helm-reference-review/`，包含正常驾驶、俯视、审查用光学特写及A/B并排。光学特写只在测试脚本中临时调整镜头，不是玩家镜头或新增游戏功能。审查者知道参考来源，A/B是匿名排版对照，不是真正双盲实验。

第一轮被否决：金属过亮、军绿偏黄、整圈磨损过于均匀、字形压扁、重复红灯与控制帽过于平面。第二轮针对这些问题调整材质、形体、印刷字和局部灯光；不以构建成功代替视觉验收。

## 继续还原：第八轮起（进行中）

用户否决第七轮的还原度，继续迭代，不能将前述构建与可达性检查当作美术通过。第八至十轮按参考面板四角拟合审查镜头，调整三块面板比例、控件间距和圆形件的非均匀缩放补偿；将舷窗总成上移0.06米，解除对控制台上缘的遮挡。玩家摄影视场与艇外摄影内容不变。保留收臂动作并把实体按钮移至右侧斜沿。

面板使用新生成的本地旧漆材质，文件与生成说明见 `public/assets/cabin/helm/README.md`；它是平铺的无控件表面资产，不是将参考整图贴在面板上。铭牌改为真实薄金属背板与透明字墨，取消图形描边；新增局部前沿补光。截图工具等待纹理载入并记录失败请求。

第十轮仍被否决：左板偏暗偏冷、中板偏亮、前沿纹理被拉长、曝光帽过亮。第十一轮分别校准材质，前沿独立使用符合长条比例的纹理密度，避免以整体曝光掩盖局部错误。审查发现桶形畸变与呼吸后处理影响投影坐标，正在校准最终像素测量；此前投影误差不得直接解释为最终画面误差。

第十一轮后处理校准后，左板样本RGB为49/62/50，参考51/64/50；仍发现中板过亮、球头偏左28像素、制动偏左17像素。第十二轮据此微调实体，重建六道宽褶橡胶套、厚圆角粗齿旋钮和粗制动护管；前裙面补上连续金属材质与全长不重复的下缘剥落遮罩。红色警示灯收拢以恢复画面内位置。新增档位变化的阴影缓存刷新，防止滑块移动后阴影停留。完整构建通过（既有chunk体积警告），仍需独立截图审查。

第十二轮实际射线双尺寸11/11通过，摇杆、制动、照明、曝光及机械臂主钮定位接近参考地标。第十三轮把旋钮压为浅圆角平顶，铭牌改为短宽粗黑体与独立物理比例背板；独立审查明确否决新牌底过亮黄绿，未因新方案而放宽标准。第十四轮纠正此配色，按原色彩图污迹关联粗糙度与中板对比，避免不相干的粗糙度噪声产生白色云团；前裙采用离散剥落与油斑，红灯使用独立内部灯芯和半透明外罩，琥珀灯仅增强局部发光，保持照亮板面的光强。当前只记录实现及审查过程，最终画面仍需核验。

第十四轮仍被否决：前裙污渍有矩形伪影。浏览器导出的真实遮罩证实，问题来自仅依赖横坐标的门限和水平裁切；第十五轮改为按物理像素等尺度的二维噪声和连续边缘轮廓，实际截图中矩形消除。调试证据保存于 `qa/helm-reference-review/material-debug-before/` 与 `material-debug-after/`。不能用平均颜色接近来掩盖这种形态错误。

第十六轮试用v2旧漆贴图，保留原版以便对照；主板增益和局部光强保持，导航键去除青蓝色。制动红帽与护圈分别定位，帽红区质心约347.4/400.9，对参考344.6/398.3，修正了此前把护圈中心误当帽中心的问题；红帽轮廓仍过高，继续修正。球头、护圈和其他控件不再重复挪动。所有11个动作在两种分辨率仍可达，阴影状态刷新通过，WebGL零错误。

灯光诊断发现现有流程在Three输出LDR画布后再经全屏ACES，限制最终高光峰值；没有为追一个灯芯像素而擅自重写全局分级。局部琥珀灯使用独立色调映射设置恢复暖黄。第十六轮的独立审查仍否决美术验收：左板偏暗、中板平滑、前裙呈水平条带；这些是待修项，不是完成结论。

同期序章由其他工作修改，截图脚本仅在隔离审查会话中跳过开场步骤以检查控制台；这一操作不是游戏流程修复或新剧情验收。正常驾驶座截图与实际射线检查在审查相机拟合前完成。新轮次的最终验证结果以对应 `qa/helm-reference-review/round*/diagnostics.json` 和审查记录为准，尚不宣称美术目标完成。
