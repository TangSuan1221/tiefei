| 牺牲结局给玩家凭空开单人逃生路 | 无远控、无替件、无人留守时无人上行；可修复时不强迫牺牲 |
| 双人救援容量临时出现 | 第三关预置双联承架与代价，第四关建立独立供氧的接驳暂存坞 |
| 已拘束同伴仍说同一段开门台词 | 对话与结尾影像按同伴实际状态变化 |
| 两个遮挡机位无法同时看到同一信标 | 改为同框标定的双校时标，共同脉冲驱动后分别布置 |
| 工程说明挤占人物体验 | 补救援名单对话、医官否定自己的不可靠健康证明等可演出场景 |

## 独立复核结论

原先三个阻断级问题已修复；身份时间线、两人转运、同伴处置、第四关揭露、第五关物理隔离通过故事大纲阶段审查。四个备选分别以责任循环、复合身份、机构权限、生态周期驱动，主题不是简单换皮。最终两个局部问题（校时标、传播结局证据范围）亦已修改。

这不等于已经验证商业成品品质或获奖能力。还需要原型/盲测回答：

1. 显影等待是否提供持续决策，还是成为拖延。
2. 早期证据是否让玩家合理怀疑，同时保留第四关身体真相的冲击。
3. 拒绝全部捷径后，是否仍存在资源足够的双人救援路径。
4. 终局管路、锁销与转运能否在视觉演出中自然理解，而不是阅读技术手册。
5. 深层干式井筒、常压服和排水设施的视觉与工程设定是否可信。
