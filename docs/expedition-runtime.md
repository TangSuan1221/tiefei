# 七关连续实景探索：运行与验收

入口：`/expedition.html`，或主菜单「实景设施探索」、视觉样板底栏「进入七关设施探索」。`?level=1` 至 `?level=7` 指定航段；航线面板也可切换。原来的 `/reference.html` 保留为用户已认可的固定美术样板。

## 当前可玩内容

- 每关 28 个舱室、4 个分区，真实连续连接，不是选择房间后传送。
- 实体滑动门、双面交互、条件隔离门、开放后的返程路线；室内与长廊尺寸不同，包含环线和远端分支。
- 每区两项固定证据/工具及一个核验终端。四区完成后可以从出口进入下一航段。必需钥匙与许可永久保留，不依赖随机奖励。
- 箱子先打开、再回收；工具回收后从场景消失；记录与终端留在原位且不能重复领用。各关的记录、工具和可选收藏内容不同。
- 连续驾驶、惯性、静态碰撞与开门碰撞、3.4 米内瞄准交互、首个实体遮挡检测，不能隔墙取物。
- M 查看测绘图，I 查看已取回物件，L 开关灯。地图和其他面板暂停驾驶。完整设施蓝图可选显示，只揭示空间结构，不揭示未探索物资。
- 分关自动存档，保存位置、视角、探索、门、物品、许可及有效游玩时间；切关后可恢复。QA 数据使用独立命名空间。

## 视觉与寻路迭代

七关分别采用矿筛转运、泵罐汇流、矿物换热、生活配给、双列动力、黑水观测和承压核心作业设施。旧版角落地标模块已退出实景生成器；工位包含各关独立的遗弃物、损坏痕迹和检修设施。吊顶、外露管束、检修面板、排水槽和局部锈水痕迹增加中尺度结构。悬浮微粒与局部冷暖照明用于氛围，不代表新增了流体或布料物理模拟。

门牌统一使用 A-01 至 D-07 的房间地址，与地图对应。两侧门牌指向实际相邻房间，显示沿设施路线的距离及开门许可；地面引导与图标不只依赖颜色。N 开关下一门导航，导航按当前许可和任务状态选取可达路径，不穿墙直指目标，不显示未知箱内物品。

`tools/expedition-art-capture.mjs` 留存逐轮真实渲染的入口、主厅、工位及参考对照；独立审查见 `expedition-art-review.md`。自动测试验证几何、可达性、七种投影轮廓及资源释放，不将测试通过等同于 AAA 视觉认证。

## 与原游戏的边界（实现范围）

这是独立的连续实景探索模式。它复用已经认可的 PBR 材质体系与七关主题，但**没有覆盖原叙事模式存档、潜艇资源模拟、猎杀系统或摄像机视频生成服务**。此模式的「核验记录」是本地任务记录，不冒充已经生成/冲洗的视频；原摄像机流程保留在原模式中。可选检修物资当前作为可回收收藏，不宣称已接入消耗式维修。

场景由 `expedition-world.ts` 生成，几何、门、物品使用同一份 `expedition.ts` 数据。地板为 −2 米，走廊顶高为 +4 米；主厅和入口采用各关独立顶高，并生成真实高低空间过渡；移动中心限制为 −1.25 至 +2.75 米并保留碰撞裕量。门动画期间保留短暂碰撞直到门叶让开，不是用于凑探索时间的等待。

## 时长

当前最高航速 1.6 米/秒。详见 `expedition-levels.md` 的可复算模型：必要路线按当前七套地图模型验证为 20–30 分钟，全搜时长依关卡分支而变化。模型含搜索、读图和操作时间；并未做真人逐关 20 分钟验收，也不保证熟练玩家不能更快通关。没有 20 分钟倒计时锁或通过减速强制等待。

## 验证

```
npm run build
npx tsx --test tools/expedition.test.ts tools/expedition-world.test.ts tools/reference-scene.test.ts tools/deepsea-renderer.test.ts tools/camera-driving.test.ts
node tools/expedition-browser-check.mjs --ready
```

内容测试检查七关图结构、门的分区隔离、所有目标先后顺序及永久授予规则。三维测试逐段检查全部连接的实际碰撞与通行并检查物品接近点。浏览器测试通过实际 W/F 按键验证移动、拾取、遮挡、存档、开门和地图暂停；测试用定位只用于布置前置场景，不能据此宣称真人跑完全关或验证探索时长。

生产构建仍有现有的大文件包体与混合动态导入警告；构建成功不代表已做低端设备性能认证。

历史 pass-4 迭代验证（不代表当前空间版本）：`npm run build` 成功；`expedition-navigation`、`expedition-art`、`expedition-world`、`expedition` 四组共 92 项测试通过，包含入口框架真实走廊边界检查；浏览器 10 项操作回归通过、错误列表为空。`qa/deepsea/art/pass-4` 留存七关各三机位和并排参考。上述结果不代表真人探索时长、目标设备帧率、流体物理或 AAA 品质已经认证。
