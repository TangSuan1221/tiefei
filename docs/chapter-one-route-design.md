# 第一章关卡动线：先看见他，再绕到能救他的位置

全局约束更新（2026-09-29）：实施以 `level-metrics.md` 为准。主游戏首关代码现已使用2.8×5×3m船体包络；后续模式仍有不同碰撞实现。本文机位处的设施控制终端必须在3.4m射线范围内，不能把远处摄影目标当作可直接操作对象；机械臂操作与曝光不能同时执行。

状态：针对最新“埃利亚斯真实获救、首章无身份疑点”的布局提案；尚未修改运行地图。局部坐标、通道尺寸、时间为灰盒起点。

## 1. 结构与玩家路线

采用一个救援主场、两侧工作湾、一条南侧回路。不要做串联三间摄影谜题房。维修笼和货仓始终属于同一个空间；玩家换位置后重新理解先前看到的设施。

主线：A入口 → B事故港 → P1首次观察 → C岸电湾 → B南侧绕行 → P2诱导与隔离 → P3救援接驳 → B核验上行堵塞 → G撤离分流井 → H下潜准备坞。

怪物路线：笼外残骸 → 装卸仓入口 → 仓内卷扬机。埃利亚斯路线：维修笼 → 短距离维护导轨 → P3套服转运托架。三条路线在怪物被隔离前不要求相互穿越。

玩家从头到尾驾驶潜艇，不在基地内步行。地图上的人行导轨仅供穿常压潜水服的埃利亚斯使用，潜艇不会穿过维修笼。所有拍摄由艇外基础摄像头完成，没有独立移动探头。

## 3. 一次首玩的顺序

### A → B：抵达，先给方向感

入口短且没有战斗。玩家在安全环境拍一次设施，学会曝光与回看。驶出后看到事故港的大吊机、北侧维修区和东侧大型货闸；远处一条稳定的小灯带引向P1。

这里先听见真实求救，目标立即变成“接近维修笼外的观察位置”。不要先塞满地图问号，也不要以大量物资搜刮推迟见到埃利亚斯。

### B → P1：看见目标，发现不能直接过去

P1与维修笼隔着开阔转运区，货架遮住怪物部分活动范围。摄影机朝东北，单卷先拍到笼内普通求救动作，再拍到笼外威胁。第一卷回答“人在哪里，是什么阻止救援”。

笼口允许玩家尝试靠近，但进入预先可见的危险带后先有金属抓擦和声纳快速接近，留出撤退空间；不是碰到隐形墙。埃利亚斯会留在笼内，不因玩家失误擅自冲出来。

P1可以看到货仓门侧的断电指示及实际电缆向C延伸。目标据现场更新为“恢复仓内卷扬机和货闸控制”，不是埃利亚斯突然要求去另一个房间拿钥匙。

### P1 → C：暂时离开他，去取得救他的能力

沿货架西侧退回岸电湾。这个短暂背离救援目标产生牵挂，但埃利亚斯没有暗藏倒计时。C内可回收液压接头并接上岸电，取得供电/关闸操作能力；电池为顺路可拿的下潜补给。

配电板明确是卷扬机、货闸、维修笼出口三条独立线路。恢复电源不会自动打开笼门，不让玩家按一次供电就莫名释放怪物。

### C → B南沿 → P2：绕到能实施计划的位置

南侧通路从B约22/58沿Z=58延伸到74/58，再向北抵达P2。不要穿过笼前怪物路线抄近道。中央撞击护墙位于约X54—68、Z53，挡住直接注视并提供退避拐角；它不是怪物永远无法越过的无敌屏障。

P2是外侧检修泊位，货闸试动和卷扬机控制接点在潜艇机械臂可达处。玩家先接操作接口，再面对北侧摄影目标；不要求相机和机械臂隔着墙同时看两个地方，也不假设相机转向后留在原地。

首次短试卷扬机并拍摄，结果片见怪物从左侧进入仓门；此后持续低速运转稳定诱导。玩家可以看见自己在P1面对的威胁，如今正在沿另一条路线远离笼子。

### P2：不要换房间，在这里完成隔离

维持诱导、落货闸、拍操作结果。视线从P2穿过南门开口指向卷扬机，仓壁不能挡住关键动作。夹肢失败片与锁销成功片从同一物理机位成立。

失败就在P2补救：保持笼门关闭、抬闸少许、继续诱导、重新落闸。没有失败后重新跑C拿同一把钥匙。能源预留一次补救，过度消耗仍能退回A补给；回退不会刷新已完成的物理隔离。

怪物关进D后，D成为不可进入的占用空间，不把下一件必须拿的道具放在里面。强行落闸压坏的只可为额外补给，不能造成关卡死锁。

### P2 → 南沿 → P3：重新进入刚才不敢靠近的空间

返回南沿，再到48/58，短距向北进入P3。此时玩家可以靠近笼口，原危险区转成救援区，形成明确的控制感变化。怪物留在货仓内，不在这段再追加突袭抵消胜利。

P3先清理导轨末端，再给笼出口供电。埃利亚斯沿约15米以内的维护导轨到达独立套服托架；路径保持在基础机位前方，艇体不会挡住最后挂接点。实际工程若挂接只能位于镜头盲区，须调整托架到前侧可见范围，而不能用全知结果镜头补洞。

结果片确认他安全就位，玩家接通信与供电。留一小段没有警报的时间，让“救到了人”成立。第一章任何录像都不暗示他的身份异常。

### P3 → B → G → H：回看旧出口，带着同伴选择新出口

回到B时，从朝入口的方向发现余震造成上行套管剪切。玩家可以近距取证或尝试有限清障，确认不是一块挡路板。不要为了强制下潜让埃利亚斯谎称上面走不了。

万斯结合G的完整井图核验底部油井电梯，得到独立回执。B到G沿南侧主航道开放，G到H是向下8米的缓坡。埃利亚斯真实帮助辨认补给接口。

H有可检查的推进电池、接驳固定与液压接口，缺件时可沿原路回C/A，已封住的D继续封住。玩家确认后才进入下一层，不因到达触发框自动切关。

## 5. 节奏、支线与现有工程边界

首次完成目标约20—28分钟，需实测：入口2—3、发现被困者3—4、岸电准备3—4、诱导隔离5—7、救援2—3、改道下潜5—7。熟练玩家可以缩短，不以固定等待强行凑时长。

只安排一个顺路资源支点：C旁较深的工具槽可取得额外电池或维修件，代价为额外驾驶与取物时间；没有关键身份文件，没有埃利亚斯可疑线索。主线最少资源必须足够完成一次合理救援和一次补救。

可复用既有工业港、吊机、货柜、灯带、驾驶、摄像/分析台与机械臂操作框架。新增需要：维修笼与套服托架、卷扬机吸引行为、货闸物理状态、同伴移动与挂接演出、基于实际结果的固定录像。

当前工程存在不同运行入口与不同碰撞/视野实现。本案是面向艇内驾驶主线的提案，不直接覆盖旧七关设计、独立步行预览或运行地图。正式灰盒前须选定目标入口。

核心验收限制：若目标入口实时完整显示怪物行为且玩家可持续照明，则这套空间仍可用于救援，但摄影将不再不可替代。必须先统一产品的实时视觉与记录视觉规则；本案不会用“相机凭空看到玩家看不到的同一位置”解释这个缺口。

## 6. 灰盒验收清单

- 含侧挂托架的潜艇从P3到H连续通行，碰撞采用实际包络扫掠。
- 四个关键机位都有真实无遮挡视线，关键对象在有效灯距内，锁销在最终画面中可辨认。
- 玩家路线不要求先穿过怪物才能去启动诱饵；怪物不会被没有依据的“安全区”强制停住。
- 没有观察结果片时允许承担不确定性，不以看完进度条替代实体操作。
- 关闸失败可在P2重试；关闸成功不把主线物资关在仓内；低电量能回补给点。
- 维修笼出口在隔离前保持关闭，玩家失误先给可撤退反馈，不靠埃利亚斯突然送死惩罚。
- 第一关成功带来一个可信同伴，任何路线都没有他的撒谎或身体异常暗示。
