## 0. 一句话

一个肯加班的深海作业员，在一次「很快就会结束的事故」里，一路听着塔台调度员万斯的美国夜班口吻往井口走；他越听越像要活，越走越像在给一口井交班。

**Logline：**  
03:14，缅因近海采矿平台解体。承包商「三号舱」弹进黑水里，以为这只是一次工事故。无线电那头的调度员万斯听上去像每个值过夜班的美国人：程序、咖啡、别慌，早餐前就能上浮。七段海底路之后，玩家会明白：事故是真的，救援也是真的——它们是同一套交班仪式。

## 1. 前提与主题（先定，再铺关）

**前提（一条）：**  
把「按程序活下去」当成信仰的人，会被程序养到成为下一班程序。

**主控思想：**  
你回不了家，因为这口井需要一个还在说话的人；而最适合说话的，永远是那个刚刚以为自己只是来加班的人。

**主题词：** 交班。  
全剧态度从「交班是体面的美国工作伦理」变成「交班是这地方活下去的方式」。主题不换，态度换。

**戏核（抽掉则本游戏不是这个游戏）：**  
**万斯必须一直在。** 不是旁白，不是任务提示器。他是唯一的同伴、唯一的地图、唯一的安慰。玩家的弱点是想听一个活人告诉自己「没事的」——万斯就一直给。他要的回报只有一件事：你继续说你看见了什么。他从不描述他自己看见了什么。

**玩家的错误信念：**  
只要按清单做、别跟调度抬杠，这事就能收工。  
（它曾经是对的：这人能活到今晚，靠的就是听指挥、签豁免、多干一班。）

**设计原则（怎么讲，不是讲什么）：**  
整晚是一次**调度通话**。每一关不是「下一张地图」，是通话里又过了一小时。气氛从工地夜班滑进鬼故事，中间没有类型换挡的鼓点——只是万斯的句子越来越像他已经说过一遍。

## 2. 世界观骨架

### 2.1 表层（开局玩家与万斯共同相信的世界）

- **时间：** 当代美国。不是神话年代，不是欧洲哥特。牌子、工会、咖啡机、红袜队比分，都还在。
- **地点：** 缅因州近海 **Harrow Field**（哈罗油田/矿权区），岸上配套镇叫 **Harrow**。镇不大，人人认识一个「在平台上干活的」。D-9 是油田最深的那口作业井，官方说法是废弃后改作应急上浮通道。
- **雇主：** **Grayhaven Marine**（灰港海事），把深海采矿包给一串分包商。玩家是分包夜里的作业员，舱号「三号」。不是英雄，不是选民，是肯签豁免协议换加班费的那种人。
- **今夜的事故：** 03:14，灰港平台解体。三号舱的逃生荚自己弹了出来——所以你还活着。浮力舱有裂缝，现在上浮等于自杀。活路：沿海底走到 D-9，坐逃生电梯。
- **万斯的身份（他自称的）：** Grayhaven 夜班调度，岸上灯塔台。他有你的舱号、你的合约编号、今晚的海况。他听起来困、专业、有一点无聊的幽默。他叫你「三号」，偶尔叫「chief」。

这一层必须先**成立**。玩家应当觉得自己在玩一个工业事故求生，而不是开场就被通知「你进了邪教」。史蒂芬·金的第一刀从来不是怪物，是：**这地方看起来还能加班。**

### 2.2 中层（玩家会自己捡到的裂口，不必一次说完）

Harrow Field 的矿权年年续，产量报表却对不上。岸上镇里，D-9 是餐桌上不说的词。工会通讯里有过一次「井下异常噪音」通报，下一期被「已关闭」三个字盖掉。平台上的警戒漆有的比平台还老。有些锁柜名牌是活着的人，有些是感恩节以后就没回镇的人。

万斯对这一切都有工地解释：旧场、旧漆、旧名册、潮汐把东西推回来。解释要**像真的**。金式悬疑靠的不是「调度在撒谎」的音乐提示，而是解释比问题更顺口。

### 2.3 深层（七关走完应当能拼上，细节留给生成）

- 这口井从来不是为了矿。钻到能「听得见」的深度之后，公司没有封井，改成了**听井**。听什么：本稿不给它人格、不给它台词、不给它要你爱它。它要的是通道里一直有一个还在报数的人。
- 「事故」是真的（平台确实碎了），也是这口井的**招聘启事**。活着弹出来的舱，就是今晚的应聘者。
- 海底那条「去电梯的路」被走过很多次。runtime 生成的残骸、生物、伪回波，都是**以前那些班次留下的形状**。不必规定它们是尸体、是工装、还是井把自己学成的样子——生成器负责形状，剧情只负责：你不是第一个走这条路的人。
- D-9 电梯是真的。它能把人送走。送走的人里，有一个留下了声音。

### 2.4 真层（最后一刀，仍保持金式「解释一半」）

万斯不是岸上灯塔里那个还在喝隔夜咖啡的人。  
他曾经是某一个「三号舱」。他走完了路，按了电梯，然后——井需要调度。于是调度一直有人。

他给的航向越来越准，因为路是他的。  
他要你描述你看见的东西，因为他那一头没有窗子，只有频道。  
他从不描述自己看见什么，因为描述会让你提前知道他在哪。

**怪物与万斯的关系：** 井是地方，万斯是地方雇的夜班。他不是魔鬼，是交班交到没有下班铃的人。这是金最狠的那种恶：它穿工作服。

**对生成内容的约束（给后续，不写进关卡表）：**  
不要给「井」一张脸、一段独白、一个要挟。恐怖落在美国夜班的熟悉感上：程序、报数、名字、加班。生成出来的东西只负责让「熟悉」一点点不对。

## 3. 人物

### 3.1 玩家（作业员 / 三号舱）

- **生理：** 成年美国人，身体能干活，不是特种兵。手记得按钮，脑子记得清单。
- **社会：** 分包夜班，岸上大概有一个等他回家的人（不必出场，万斯会随口问）。为了加班费签了今晚的豁免。不是「被选中的人」，是「今晚还肯下井的人」。
- **心理：** 相信程序。不信神迹，信清单。害怕的不是死，是死得不明不白、让岸上那个人去填表。
- **错误信念生根的原初场景（不必在游戏里演，但要决定他怎么听万斯）：** 早年某次工地，他没听调度、自己判断，结果害了别人——或者相反：他听了调度，别人怪他。无论哪一种，今晚他都会把耳朵交给频道。
- **弧（游戏里能看见的，不是独白）：** 从「万斯让我活」到「我在替万斯活」。结尾他可以拒绝交班、可以接班、可以假装没听懂——本稿不锁结局，只锁他必须做一次**关于说话**的选择：关掉无线电，还是把频道留给他之后的那个人。

### 3.2 万斯 · 沃尔特·万斯（Walt Vance）

始终在。七关里他可以短暂静默，但不能消失。静默本身要像故障，不像过场。

| 维 | 内容 |
|---|---|
| 生理 | 五十多，烟嗓，夜班人口干。语速不急。句子短，爱补半句。 |
| 社会 | 缅因人。工会、程序、气象、港口。会提岸上无关紧要的事：咖啡焦了、红袜队、老婆的烤盘。这些闲话是开局「平淡」的来源，也是后期的刀：他提的岸上细节会开始重复，或对不上季节。 |
| 心理 | 他需要频道那头有一个还在报数的人。这是他的班。班不能空。 |
| 具体类别 | 不是「骗子」，是**职业强迫症的记录员**。他攻击玩家的方式是给正确答案。 |
| 对主题的态度 | 交班是体面。一直是。到最后他仍然这么认为。他可以是全剧唯一不改态度的人。 |
| 对立统一 | 两人被同一条无线电绑死：玩家需要他才能走，他需要玩家才能继续当调度。谁把频道关掉，谁就先死——或者先自由。 |
| 他的刀 | 永远有下一句有用的话。航向、深度、别开灯、现在拍。有用，所以你不挂断。 |

**万斯不是反派独白机器。** 他大部分时间真的在帮你活。金式假盟友：帮助是真的，目的不是。

**口头禅（可作全剧回声）：**  
「按住按钮说话。」  
开局是规程。终局可以反用：他求你按住。

### 3.3 不在场的美国人（只需职能，不必全写进关）

- **岸上的人：** 一个等三号舱回家的人。万斯会问。玩家可以不答。这个人的作用是让「回家」有重量，不是支线。
- **公司：** 灰港海事。它的恶是表格和续约，不是披风。
- **Harrow 镇：** 封闭社会的陆地端。生成内容里出现的名牌、涂鸦、录音，口音应该是美国东北岸，不是欧洲神秘学。
- **以前的三号舱：** 玩家会在某关意识到「有人用过这张椅套 / 这份清单 / 这个舱号」。不必遇见完整的前任；遇见声音、遇见习惯就够。

**四角（保证中段不是只有「人 vs 怪」）：**

1. **玩家** —— 要回家，要程序。  
2. **万斯** —— 要频道不断。  
3. **井 / 地方** —— 要一个还在说话的人（无台词，只通过生成压力出现）。  
4. **公司 / 镇** —— 要这件事今晚看起来仍像事故（文件、漆、过期的应急图）。

四角各用不同方式打「你听调度就能活」这个信念。

## 4. 七关：只写走向，不写细节

runtime 负责：这条走廊长什么样、回波是友是敌、片子里闪过什么。  
剧情只负责：这一关**通话的气温**、**玩家该新知道哪一类事**、**对上一关的哪句话进行翻案**。

心理拍沿用现有七关节奏：教 → 不安 → 熟练 → 背弃 → 压缩 → 惧 → 放。剧情叠在这根骨头上，不另造一根。

### 第 1 关 · 事故还像事故（teach）

**玩家以为：** 平台碎了，我运气好，听万斯就能走。  
**万斯：** 完全的美国夜班调度。先别动推进器。母船没了，这是坏消息；你弹出来了，这是好消息。浮力舱裂了，现在上浮是自杀。沿海底去 D-9。电不够养灯，用回声看形状，看不清再拍。  
**本关剧情职能：** 把「工事故求生」演圆。允许生成内容里出现一个还说得通的异常（一块不该在作业区的东西、一个没有编号的回波），万斯必须有工地解释。  
**翻转：无。** 这一关禁止揭秘。平淡是资产。  
**通话气温：** 困、准、有一点笑话。玩家应当愿意把耳朵交给他。  
**卡关钩：** 他要一份事故报告。那团没有编号的回波必须拍下来（线框才有名字），采矿模块必须停靠。生成器必出：残骸节点 + 可解释的敌/友回波。卡住时他催的是「报告空着这一栏」，不是「按摄像头」。

### 第 2 关 · 解释开始比问题顺口（unease）

**玩家以为：** 废弃管线，听他的，走刷了警戒漆的那根。  
**万斯：** 仍在教你干活。漆雷达看不见，所以要拍。他开始用「旧场都这样」填所有缝。  
**本关剧情职能：** 第一次让「熟悉」微微不对。不对必须能被当成年久失修。生成器给什么形状都可以，剧情只要保证：万斯的解释来得太快，快得像他今晚不是第一次说。  
**翻转（小）：** 不是「他在骗你」，是「他太熟了」。熟可以是老调度，也可以是别的。玩家此时还应该选择相信老调度。  
**卡关钩：** 他要看哪根刷过警戒漆。雷达看不见漆，所以必须拍分叉。生成器必出：镜像分叉，一侧余烬漆、一侧骨白编号，阀在有漆那根上。卡住时他催「拍分叉 / 顺着有漆的那根」。

### 第 3 关 · 你开始会了，路也开始会了（skill）

**玩家以为：** 我上手了。热泉、充电、节奏，都是技术活。  
**万斯：** 夸奖。美国人夸人的方式：不煽情，说你没把舱撞碎。然后给你下一份准到可怕的预告。  
**本关剧情职能：** 兑现「工业求生」的承诺（玩家确实在变强），同时让路像**记得人**。某次生成的威胁或机关，会走万斯刚刚报过的点。万斯说潮汐、说回流、说「它们就爱待在泵边上」。  
**翻转（中小）：** 预告准，不再只是专业，开始像记忆。  
**卡关钩：** 他要你数喷口。喷口和贴壁回波必须坐在他刚报的航向上。生成器必出：热泉机关 + 回波钉在 advised heading。卡住时他催「数喷口。它们就爱待在我报的那个航向上。」

### 第 4 关 · 救援图比你的眼睛清楚（betray · 中点）

**玩家以为：** 前面是补给/充电，他让我别浪费电去拍。  
**万斯：** 第一次明确让你**别看**。这是全剧他从「帮你看」变成「替你看」的点。  
**本关剧情职能：** 中点。胜利假象与失败假象叠在一起：你可能充到电、活过伪回波，同时发现他的图和你的残骸对得过死——像他不在水面以上。  
**翻转（主翻转 1）：** 灯塔不在你想象的那个岸上。他仍可能是活人，但空间关系变了。此后每一句「我这边更清楚」都带毒。  
**注意：** 本关仍不要把「他就是井」说破。金式中点是换房间，不是换宇宙。  
**卡关钩：** 他让你别拍那两座对称块，但中间那根真充电桩可以拍——线框仍要有名字，下一段才能接上。生成器必出：双块镜像 + 单独的充电桩。卡住时他催的是桩，不是那两张嘴。这是本关唯一能解开「他说别看 / 游戏要你拍」的办法。

### 第 5 关 · 工业还在转，班却不该还在（compress）

**玩家以为：** 更深的工业层，穿扇叶，切一门，继续去电梯。  
**万斯：** 航向开始和常识拧。电源「不知道从哪来」他会说成笑话，然后不笑了。闲话里的岸上细节出现错季、重复、或像从旧日志里读的。  
**本关剧情职能：** 封闭社会现形。生成内容应能拼出：这套设施不是今晚才碎的，它碎过、开过、又碎过。名字、漆、还在转的电，都指向**有人把班留下了**。  
**翻转（主翻转 2）：** 事故不是起点。事故是循环里的一格。你仍可以当自己是这一格里的幸存者——只是「幸存者」这个词开始难听。  
**卡关钩：** 电扇还在转，班还没交。他要缺口的计数，和门锁生锈的那一侧。生成器必出：扇叶周期 + 一次切割的薄弱点。卡住时他催「拍缺口 / 切割器一次，别切错」。

### 第 6 关 · 有东西跟班，但不下班（dread）

**玩家以为：** 井壁这一段很干净。干净得不对。  
**万斯：** 第一次真正把「看」交给你：如果有东西贴着走、不攻击，不要开灯。拍。看它的脸。想再拍的话，脸可能换了。  
**本关剧情职能：** 把前任班次从「暗示」推到「同行」。生成器决定那张脸是空的、是工装、是你自己的轮廓，还是什么都看不清——剧情只要求：它保持距离，像值班，不像捕食。万斯会开始要你**描述**。描述是他的薪资。  
**翻转（主翻转 3）：** 你不是在逃一个怪物。你在被一班人（或一个班的形状）护送去交班。万斯的关心和这东西的贴行，是同一种工作。  
**卡关钩：** 他第一次把「看」交还给你：跟我说它的脸，不要开灯。生成器必出：保持距离的伴行回波。卡住时他催「拍。描述。走。别跟它耗。」描述是他的薪资，也是本关的通关动作。

### 第 7 关 · 电梯是真的（release）

**玩家以为：** 到了。D-9 在正上方。拍舷侧符号，开锁，回家。  
**万斯：** 仍帮你开锁。然后提出全剧唯一不像程序的要求——例如进井前关掉无线电，不要问为什么。要求可以因生成而换说法，职能不能换：**他要你在最后一步单独做决定，同时他比任何时候都需要你留下声音。**  
**本关剧情职能：** 安全港就是井口。金式战斗发生在「看起来能回家」的地方。  
**翻转（终翻）：** 电梯能送人走。走的人里需要留下一个声音。万斯希望那个人是你——或者希望那个人仍是他，而你只是把今晚的路走完、把描述交齐。  
**结局态度（不锁分支，只锁问题）：** 玩家必须回答「频道给谁」。回家、接班、静默、把井封上，都是这个问题的不同答法。不要用巧合救他，不要让公司来电，不要让怪物开口求爱。  
**卡关钩：** 舷侧符号是钥匙。拍它，抄到图案锁上。进井前关掉无线电——这句不像程序，但是本关他要的最后一件东西。生成器必出：驳船残骸 + 图案锁，竖井里不许再撒货箱。卡住时他催「舷侧。从左到右。」不替玩家回答频道给谁。

## 5. 翻转阶梯（给审阅：每一刀翻的是上一刀的哪一句）

| 关 | 当时信的 | 事后看是 |
|---|---|---|
| 1 | 这是事故，调度在救我 | 事故是招聘启事；调度在接新人 |
| 2 | 他熟是因为干了二十年 | 他熟是因为路是他的 |
| 3 | 预告准是因为专业 | 预告准是因为记忆 |
| 4 | 他的图更清楚，因为他在岸上 | 他的图更清楚，因为他不在你以为的地方 |
| 5 | 今晚才碎 | 碎是班次；电还在是因为班不能停 |
| 6 | 有东西在猎我 | 有东西在带我去交班 |
| 7 | 电梯是出口 | 电梯是岗位 |

史蒂芬·金的悬疑不靠「突然换反派」，靠**同一句美国闲话在第七关变得没法听**。所以开局必须真的平淡：咖啡、程序、chief、别动杆。若第 1 关就阴，后面的翻案没有地方落。

### 4.1 卡关钩（每关一条，生成器硬约束）

每一关只种**一件**万斯要的东西。这件事同时是剧情拍，也是防卡。

规则：

1. **契诃夫：** 进关 brief 里他要过的那件实物，生成结果里必须在。不能口头要「警戒漆」而线上没有漆。
2. **金式催促：** 玩家在站点闲着或做无用功时，无线电再催一次。催的是日志/描述/交班，不是键位。同一扇门只催一次。
3. **通关门映射：** 钩子指向现有四步（拍清楚 → 去他要的节点 → 开锁 → 拍出口），不另造第五步。第 4 关例外：他禁止拍双块，钩子改指中间那根真桩——否则「别看」会把人锁死在「线框没名字」。

| 关 | 他要的 | 生成必须兑现 | 卡住时催哪一步 |
|---|---|---|---|
| 1 | 没编号的回波 + 采矿模块 | echo-wreck | 拍回波 / 停模块 / 拍出口 |
| 2 | 哪根刷过警戒漆 | paint-fork（镜像，漆在真路上） | 拍分叉 / 走有漆的 / 拧阀 / 拍出口 |
| 3 | 喷口的计数 | period-heading（回波钉在他报的航向） | 数喷口 / 过热泉墙 / 拍出口 |
| 4 | 中间那根真桩，不是那两座 | true-charge（双块镜像 + 独立充电桩） | 拍桩不拍嘴 / 去桩 / 拍出口 |
| 5 | 扇叶缺口 + 生锈那一侧 | fan-and-cut | 拍缺口 / 去门 / 切一次 / 拍出口 |
| 6 | 它的脸 | watcher-face（伴行，不猎） | 拍脸 / 保持距离 / 拍出口就走 |
| 7 | 舷侧符号 | glyph-barge（驳船 + 图案锁，井内无货箱） | 拍符号 / 驳船 / 对锁 |

实现落在 `src/pod/gen/story.ts` 的 `STORY_HOOKS` / `requireHook`，生成器 `ensureHook` 缺件就补，运行时闲置后 `queueRadio` 万斯那一句。

## 6. 万斯声线：七关只变气温，不换人

他从头到尾是同一个人。不突然诗意，不突然邪典，不突然承认「我是怪物」。

| 关 | 口气 | 他做什么 | 他不做什么 |
|---|---|---|---|
| 1 | 夜班、规程、小笑话 | 教你活 | 不谈井的历史 |
| 2 | 仍是老师 | 用「旧场」填缝 | 不承认解释太快 |
| 3 | 夸你，像工头 | 预告下一拍 | 不解释自己何以预知 |
| 4 | 第一次不耐烦 | 让你别拍、信他的图 | 不解释他在哪 |
| 5 | 闲话开始错季 | 仍给能用的航向 | 不谈自己下过井 |
| 6 | 要你描述 | 把「看」还给你 | 不描述他自己看见的 |
| 7 | 规程里出现一句不像规程的 | 帮你开锁，然后要频道 | 不求饶、不告白、不讲解宇宙 |

若某次生成让环境极满，仍然优先加万斯一句短的，而不是加一段世界观说明书。金的广播恐怖是：**人还在说话，所以你还没死；人还在说话，所以你还没自由。**

## 7. 类型与边界（本文遵守的，供拍板）

- **主类型：** Horror（恐怖）。地方是鬼屋的工业版；万斯是假盟友；井是没有台词的 double（它要一个会说话的你）。  
- **副类型：** Thriller（你在调查的同时会被走完）；一点 Detective（揭露靠物证和生成里的名牌/录音，不靠灵光一闪）。  
- **世界观国籍：** 美国东北岸劳工。名字、公司、闲话、工会、球、咖啡、豁免协议。不要欧洲神秘学腔，不要教主，不要拉丁祷文。  
- **金式，不是洛夫克拉夫特式：** 怕的是交班、名册、还在转的电扇、一个听起来像舅姥爷的调度员。宇宙可以大，口吻必须小。  
- **不写死的：** 每一关的具体残骸、生物种类、片子构图、符号长什么样。那些归 runtime。剧情只收：这一关通话结束时，玩家对「我能不能回家」的答案必须比进关时更坏，或更复杂。

## 8. 请审的三件事

1. **开局平淡是否够平？** 第 1 关是否允许完全不揭秘，只把事故演圆。  
2. **终翻是否接受「万斯是上一班三号舱」？** 这是最金的一种（守护者/看护人）。若太直，可改成：万斯仍是岸上死人留下的频道，井学会了接听——那就更空、更冷，但会削弱「两个人被一条无线电绑死」。  
3. **结局：** 已按「频道给谁」写出八种通关结局，见第九节。中途死亡不算通关。

## 9. 通关结局（审阅）

走到 D-9 井口才算通关。中途失压、撞死、电尽，是失败，不是结局。

**危机（静态，必须让玩家停住选）：**  
井口两根杆，没有第三根从天上伸下来。

1. **人走哪：** 进电梯 / 留下。  
2. **频道给谁：** 关掉 · 开着把班留给万斯 · 开着自己接班 · 开着不说话（空频）。

八个结局都是这两根杆的组合，外加一路上你有没有一直「描述」、有没有一直信他。公司不来电，怪物不开口，没有巧合救援。

前提只有一条，结局是它的八种证法——同一句「交班」，态度不同。

| 编号 | 名字 | 频道给谁 | 味道 | 金式收法 |
|---|---|---|---|---|
| A | 早餐 | 留给万斯，你以为回家了 | 假好 / 双重结局 | 轮回：卡车里的无线电 |
| B | 交班 | 给你 | 坏，完整 | 呼应：你说出「按住按钮」 |
| C | 挂断 | 谁也不给，你走 | 苦 | 反讽：下一班没有地图 |
| D | 空频 | 频道在，人空 | 真结局 | 点睛：静电本身就是拒绝 |
| E | 封井 | 掐死 | 苦 | 反用口头禅：他求你按住，你不按 |
| F | 记录 | 井拿走你的描述 | 坏 | 你一直报数，报到只剩报数 |
| G | 捎上 | 两人抢一个出口 | 反讽坏 | 电梯只送走声音，不送走成对的人 |
| H | 岸上 | 你把班带回镇上 | 隐藏 | 家里那个人听见的是调度口吻 |

### A. 早餐 `end.breakfast`

**你做了什么：** 进电梯。无线电开着。你仍把万斯当调度，向他报了最后一次深度。他让你上去，语气像下班铃。你照做。

**万斯最后一句：** 「上去吧，chief。咖啡我这边还热着。」

**落幕：** 你上了 Harrow 的岸。天光。diner 里有烤盘和隔夜咖啡。有人问平台的事，你说事故，很快就会有人来处理。你开卡车回家。副驾没有人。走了两英里，没插电的车载台自己响了一下：「三号舱，按住按钮说话。」你没有带无线电上来。

**证明：** 你信了程序，所以你活着离开——程序把下一班的耳朵，安在你家里。  
**触发（剧情层）：** 进电梯 + 全程大体听万斯 + 没有在第 7 关关掉频道。最容易走到的「好结局」，必须带这一刺，否则开局的平淡没有回收。

### B. 交班 `end.handoff`

**你做了什么：** 不进电梯。坐进井口那张不该还在的椅。戴上他的耳麦。万斯的声音变薄，像人把班交给下一手。

**万斯最后一句：** 「表在右手边。第三列写深度。别描写你看见的——让他们说。」停半拍。「谢了，chief。」

**落幕：** 频道里先是空白。然后有一个舱号弹出来，口音比你今晚更年轻。你听见自己说：「三号舱，我是灯塔。先听我说完，别动推进器。」咖啡的笑话你也会说。你说得比他自然。

**证明：** 把「按程序活下去」信到底的人，会成为下一班程序。这是前提的正证，也是万斯弧的完成：他终于下班。  
**触发：** 留下 + 接过频道。一路上越听他的，这张椅越像为你留的。

### C. 挂断 `end.hangup`

**你做了什么：** 进电梯。进井前关掉无线电。万斯还在说航向，你把旋钮拧死。你上去了。

**万斯最后一句：** （被切断，半个词。）「——按住——」

**落幕：** 你活着。Harrow 的人把你写成幸存者。三个月后地方报一条栏外：灰港近海又碎了一艘作业艇，无调度记录，唯一舱号在海底迷了航。你知道那人没有灯塔。你没有告诉报社。

**证明：** 拒绝交班能救你自己；班空着，下一个人没有地图。反思想：不听调度也能活，但「活」会变成你欠着的那一班。  
**触发：** 进电梯 + 第 7 关关掉无线电。不要求你看穿一切，只要求你在最后一步不听话。

### D. 空频 `end.deadair`

**你做了什么：** 进电梯。无线电开着，但谁也不说话。不按按钮。也不关。万斯等你描述。你把按钮按在半途——频道占着，里面是静电。

**万斯最后一句：** 「三号？我这边只听见载波。」更低：「别把班留空。」

**落幕：** 电梯上升。井还在。下一次事故里，有人会叫灯塔，灯塔会应一声沙，没有句子。那个字写不完。你上岸以后很少接电话。不是怕，是你知道空着的频道比有人说话更吵。

**证明：** 井要的是「还在说话的人」。你给它一条还在的线，不给它人。这是全剧唯一一次既不接班也不装没看见。  
**触发：** 进电梯 + 频道开着 + 终局保持静默（整晚也可以少描述，但最后一步必须空）。建议作为真结局：要走到这里，得先明白他在要你的声音，而不是要你的命。

### E. 封井 `end.seal`

**你做了什么：** 不进电梯。堵井口、掐电、让升降作废。你可能活着爬回浅处，也可能把自己留在门这边。无论哪一种，D-9 今晚不再送人。

**万斯最后一句：** 「按住按钮说话。」这是全剧第一句的反用：他在求你。求完他仍不骂你，仍是夜班口吻。「班不能空，chief。」

**落幕：** 电扇还在转的那一层，声音一层一层掉。Harrow 镇上，有人等三号舱回家，等到天光。井不再招聘。它会等。金不给「你拯救了世界」，只给「你今晚不让它招到人」。

**证明：** 交班是这地方活下去的方式——所以停班是唯一能伤它的动作，代价是你或岸上那个人。  
**触发：** 留下 + 关掉或摧毁通道（焊、堵、断电）。一路上若很少对万斯描述，这条更顺。

### F. 记录 `end.log`

**你做了什么：** 七关里你一直按他的要求报你看见的。第 7 关你仍在报：符号、井口、深度。电梯可以动，也可以不动。人已经不重要。

**万斯最后一句：** 「收到。名字对。」停顿。「对什么对？对名单。」

**落幕：** 灰港海事的值班簿多了一夜：字迹方正，像填表。内容全是你的描述，没有一句是你想回家。舱体后来被捞起来或没有。广播里偶尔有人用你的句子报海况。你听着像自己，作息像万斯。

**证明：** 错误信念「照清单报数就能收工」被执行到只剩报数。这是惩罚性反讽，不是被怪物吃掉。  
**触发：** 高「描述」次数（第 6 关尤其听话）+ 终局仍在向他汇报。进不进电梯都可以，记录优先于早餐。

### G. 捎上 `end.takehim`

**你做了什么：** 进电梯，并且违抗他「进井前关掉无线电」。你想带他走。你喊他的名字，要他上来。

**万斯最后一句：** 「别。井一次只放一个声音走。」几乎是温柔的。「你上去，我留着。反过来也行。别成对。」

**落幕：** 电梯动了。两个人的声音挤在同一个载波里，像抢一根氧气。升到某一深度，其中一个人先从句子里掉出去——可能是他，可能是你。上来的那一张嘴，说话会串味：你的事用他的口气，或他的班用你的名字。diner 里点菜的人停一秒，说你听着像两个。

**证明：** 对立统一被强行一起带走，绑死他们的那条无线电就翻过来勒。善意在这里是错的动作。  
**触发：** 进电梯 + 终局无线电开着并且对万斯说话 / 叫他一起走。情感上最像「好结局」的操作，必须收到最像惩罚的账。

### H. 岸上 `end.shore`

**你做了什么：** 进电梯回家。路上你回答过万斯「岸上有没有人」。你到了那个人的厨房。

**万斯最后一句：** 可以没有。他在你上岸前已经把班交回静电。或者只剩半句：「替我问她烤盘。」

**落幕：** 厨房灯。有人问你累不累。你说「先听我说完，别动」。你自己听见了这句。对方笑一下，然后不笑了。窗外 Harrow 很安静。你后来会在半夜把对讲机的旋钮拧到空段，听有没有人报深度。

**证明：** 班可以不上井口那张椅，也可以被你装进行李。这是金最家常的一刀。  
**触发：** 进电梯 + 对「岸上的人」有过一次诚实回答 + 没有封井、没有空频。隐藏：不是更酷，是更近。

### 互斥与优先（给以后做门控，现在不写代码）

- **记录 > 早餐：** 报够了数，就不要再给干净的 diner。  
- **捎上 > 早餐：** 你喊过他一起走，就不要假装只是普通上浮。  
- **空频 > 挂断：** 频道开着但不说话，比拧死旋钮更难，也更「看见了还拒绝」。  
- **交班 与 封井** 都是留下，用最后一下区分：戴耳麦还是堵井。  
- **岸上** 可以叠在早餐或挂断之上，作为家常尾镜头；若单独做成结局，优先于早餐的卡车刺，改成厨房刺。

### 不要做的结局

- 公司派船来接。  
- 井开口求你、爱你、给你许诺。  
- 万斯承认「我是怪物」并自我了断来成全你。  
- 醒来发现是梦 / 还在铺位上。  
- 八个结局八套世界观。它们必须是同一口井、同一条无线电的八种交班法。
