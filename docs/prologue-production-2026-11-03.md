# 入港前序章 · 制作记录

入口：主游戏 `/` 新游戏，PodRun → HarborRescueSite。序章独立于五章，结束后接现有第一章。继续旧档不补播；开发用 level=2/3 直达入口不插入首航。附件为字幕与物体特写参考，未附红区平面图，因此沿原起点后方负 Z 方向延长。

## 实现

IMPLEMENTED：在原检查气闸后延长水道，世界范围 X5–17 / Y−3–4 / Z−44–4，净宽12米、净高7米。与既有水域做壳体并集，入口没有残留封墙。出生点 (11,0,−36)，原起点 (11,0,10)，首航点 (11,0,16) 不动。壁面标记属于 decorColliders；壳体属于 colliders。

教学顺序为手动坐标、照明、档位、前进、后退、上浮、下潜、抬头、低头、回正定深、驶向入口、机械臂作业。前进至少1米，后退/升降至少0.5米，俯仰各改变4度；实测发现俯仰残余会让持续推进触底，因此新增回正定深：俯仰误差<0.6°、高度误差<0.25米且角速度/升降速度稳定，再驶向入口。教学提供实时俯仰/深度/航速，抵达操作范围并停车后才进入机械臂教学。门打开且臂收妥才交接第一章。没有计时自动授予完成。机械臂复用真实门控、3.4米射线、照明供电与可取消自动作业，不新造远程操作。

实体设备自动聚焦、白色悬浮操作说明和下方陆地频道字幕。驾驶教学的特写3秒后释放，允许观察水道及自由环视；输入、灯光、档位保持聚焦到操作完成。坐标可用实体键盘或电脑数字键，Tab换字段、Enter写入；这一路径只在坐标教学期间捕获数字，避免与原工位快捷键冲突。X/Z 档位快捷键在共用驾驶区可用。仪表仍为 X/Y/DEPTH，教程说明第三轴用深度表示，实际录入为11/16/1012，内部换算为11/0/16。

万斯先介绍陆地指挥员身份，再逐项引导。语音使用现有浏览器中文合成朗读并遵守静音设置，NOT_IMPLEMENTED：真人配音素材。序章期间不推进第一章任务播放器、不预热故事视频。save 中保留 step/gears/anchor；旧档无此字段则继续原流程。

2026-11-03 用户修订提示节奏：每步先只显示下方万斯字幕（无声时按字数计时，有语音时延到朗读结束，上限再加8秒），字幕结束后顶部才以打字动效弹出操作指引；指引固定单行，超宽时缩小字号而不换行。原指引中的说明性内容（第三格是深度、切档不会开船、操纵杆左右拨转向）移入万斯台词。实时俯仰/深度/档位读数在指引打完后显示。浏览器证据 qa/prologue-caption（check.mjs 与 01–03 截图，errors 为空）。

## 2026-11-03 输入阻塞复现与独立盲测迭代

用户实测报告无法输入。另建不继承聊天上下文的测试agent，仅按画面操作，不读源码、不调用运行时对象、不改状态。基线1280×720复现：实体数字键无效；点击Y再敲数字仍写进X。证据 qa/prologue-blind/baseline.md、baseline-y-click-writes-x.png。

根因：教程镜头每帧重置deviceZoom，但普通deviceClick仍把首次点击当“进入设备特写”并提前返回，导致每次鼠标点击都被吃掉。CabinThree现在记录实际教学聚焦状态，已聚焦时直接把点击交给实体控件/屏幕字段。其他设备特写逻辑不变。

旧回归仅用电脑键盘+Tab，漏测了用户提示所要求的鼠标选字段和实体键盘，这是原验证范围的缺口。新增tools/prologue-pointer-check.mjs以真实鼠标完成选字段、数字录入和写入，结果PASS、errors=[]，证据qa/prologue-pointer/result.json。脚本读取浏览器已加载的声纳模块URL，避免Vite带时间戳模块与无时间戳模块产生两份WeakMap而误判空值；不调用动作或写入游戏状态。

独立agent修复后已完成鼠标坐标路径及电脑数字键/Tab/Enter路径。开发服务因证据文件变化发生整页重载，连续跑测改用无HMR生产预览 http://127.0.0.1:5296/ 。中断时“继续下潜”恢复到低头教学成功。最终连续通关结论以本节后续补记及qa/prologue-blind报告为准。

本轮沿用上表全部44项审查：变化限MET-029/039实体点击可达、MET-022/031验证范围补齐；不改叙事正典、地图几何、资源、相机摄影权限或碰撞通道。真人盲测与配音仍为GAP；独立agent盲测不等同真人测试。


最终独立盲测结论：固定预览中从新游戏连续完成全部序章。agent只用可见提示和真实输入，门牌3.2米时停稳进入机械臂步骤，按F开门并自动收回；序章提示消失，出现“视频通讯·艾里亚斯 / 求救呼叫 / 点击前往分析台【通讯】接听”及当前任务，确认交接第一章。未再遇硬阻塞。
