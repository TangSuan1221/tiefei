# 第一关视觉迭代 · 2026-10-11

状态：IMPLEMENTED（以下局部）／GAP（商业写实品质及全面回归）。runtimeProfile：main-authored，`/` → PodRun → HarborRescueSite / PodExpedition；渲染为 Three.js，未迁移 UE5。

本轮以用户第二关截图和当前第二关代码为基准，分派环境、海水、人物与独立视觉审查，并使用不继承项目上下文的独立玩家。Blender MCP 本地 9876 已实际连接并用于资产创建、保存和预览。当前没有名为 ultracode 或 /loop 的工具；迭代由实际修改、实机截图、独立审图、再修改组成。

## 已实现

- 探照灯的水体散射读取真实阴影深度，闭合门后不再无条件透射。暖白探照灯、较弱环境填充、接触遮蔽与长距离实时灯衰减改善近处结构；实时曝光采用第二关的0.4186基准。无灯和录像独立的规则保留，录像专属怪物仍由现有adapter控制。
