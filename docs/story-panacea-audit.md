# Panacea版全项审查

本次为新正典重写：序章+五章、替代分支、事故时间线、调查链与日志设计。仅作者文本审查和阅读工具验证，未进行独立玩家盲测或3D游玩。旧审查保留历史用途，不作为新稿通过证据。

## 与用户设定的对应

资源枯竭、物种灭绝、太空转深海研究写进序章；热能和再生医学动机通过简报建立。维拉、临床加速、VIP疗养与物资歧视通过文件及仓库对照查出。德尔罗伊与孙子的申请先出现，再有老人养章鱼的生活片段，最后在-3层核验其行动，章鱼保留到-4层。平静既是疗效和接受者的真实体验，也呼应主角对岸上噪声的厌倦。

最新明确要求覆盖旧设定：删除尼科、莱娜主线；不再用病毒/饥饿捕食解释怪物；首关保留尸体但不揭露兄弟身份；第三个可玩层是-2层，-3层是第四关。Alex暂统一为艾里亚斯。主存按物资存储舱解释。

## 本轮发现与处理

1. 若所有恐怖都写成扑杀，会破坏无恶意介质的核心。现稿威胁改为患者的邀请、合流、失去拒绝意识的保护、德尔罗伊修护潜艇导致挤压，以及章鱼把潜艇送回父亲处。主角的生命风险仍真实。
2. 水本身不等于介质：普通兄弟会溺亡，接受结局必须真实处理并等待适应；声波不感染。医院早期不充分知情和晚期明确选择分开，不能替死者宣称同意。
3. 章鱼若几天内无原因变大，因果不足。饲养与学习跨多年，介质接触与加速成长跨六周，通过多段日常影像说明。具体时间是本轮提案。
4. 艾里亚斯既非VIP又先治疗的冲突：他是商业化前的员工临床受试者；德尔罗伊争取的是商业化后的孙子资格，二者不矛盾。
5. 万斯原稿全程在线与新要求冲突：序章失联，中途信息由日志/艾里亚斯/基地内线维拉承担，底站供电和上行恢复后才回归。
6. 拟声与父子声路来源：求救走固定水声通信装置；拟声组织贴固定通话器；Boss阶段转接真实能源层声音，不凭空播放记忆、不冒充孙子或父亲。
7. 首关出现尸体与旧无身份线索约束：显示不具识别信息的尸体，只到第四关旧监控+位置比对+本人承认才揭示。救艾里亚斯仍然救出真实困境，不撤销其早期帮助。
8. 末关若关门阻断父子团聚，会使选策略自我打脸：关闭的是维护支路与接驳水道之间的隔断，父子之间的水道保留；当前照片明确章鱼在维护支路内。
9. 不使用父亲声音仍有可行路线，不让亲情谜题成为唯一答案；资源与绕路未实测，不能只靠文字保证可玩。断合作无幽灵同伴。

## 因果限度

德尔罗伊录像证明其动作先后，门控/报警支持先开路后进水；公司文件证明优先供能，不能据此宣称公司蓄意设计所有死亡。潘acea的接触路线和集体记忆来自维拉研究记录，网络范围与科学机制未被主角完全证明。章鱼行为与旧饲养影像共同支持父子依恋的理解，但不虚构它向人类口述了全部内心。

自愿留海的患者有明确回应；兄弟有明确拒绝与挣扎。艾里亚斯承认未开返回门，是对其责任的关键互证；镜头未拍到的操作不由旁白伪造成当前直接所见。尸体不复活，介质不逆转已经发生的死亡。
