# 全关卡通行门设计规范

用户指定参考：codex-clipboard-537449bf-b018-4c01-92cc-0637ace84d43.png（2026-09-27）。适用于全部七关的通行门，不仅第一关主门。

- 工业承压门：厚门框、多层密封圈、可读的锁臂／液压机构、管线、螺栓与腐蚀分层。不得用无结构平板代替最终资产。
- 蓝绿色应急灯条属于门体和门框内嵌硬件，独立供电，不受玩家照明开关影响。关闭探照灯时仍可识别通路。
- 关闭时门缝灯条可辨认；开启后固定门框保留引导光。双面可见，不只服务某个审美截图机位。
- 侧边红色灯表示门已关闭／锁住；开启后切换浅色状态。灯条表示通路位置，不意味着已获得通行权限。
- 维持黑暗环境，不以照亮整个房间代替应急灯；灯光不能穿墙，也不能替代碰撞与真实门状态。
- 门尺寸根据潜艇净空调整，不能机械照抄参考图尺寸造成堵路。材质与细节可随关卡变化，但以上视觉语义一致。
