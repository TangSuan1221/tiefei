# 七章主航线叙事

接入入口：`/` → 开始下潜（PodRun 主航线）。独立的 expedition.html 设施探索模式仍是另一套运行时，本次没有伪装成两套模式已经共用剧情/存档。

## 因果主线

| 章 | 主要疑问 | 证据位置 | 后续回收 |
|---|---|---|---|
| 1 事故报告的空栏 | 敲击是否只是设备故障 | 采矿模块与无编号回波 | 三次敲击贯穿维护回路 |
| 2 还没干透的路 | 谁维护废弃航路 | 分叉警戒漆 | 漆与通路确实有效，但废弃说法可疑 |
| 3 航向记得你 | 万斯知道的是地形还是流程 | 周期喷口 | 编号和节拍成为跨站线索 |
| 4 不准留下的底片 | 为什么禁止观察两侧 | 真充电桩 | 实际帮助与限制观察同时存在 |
| 5 没交完的班 | 设备为什么还在工作 | 扇叶缺口、锈侧锁 | 地热和继电器解释持续供电 |
| 6 留给谁的脸 | 声音是否证明有人在线 | 伴行目标 | 录像音轨重复支持回放推断，不确认怪物身份 |
| 7 接班回路 | 要把什么带回海面 | 驳船符号与调度说明 | 回放机制得到解释，当前声音的身份仍未证实 |

每章五个去重触发：启程 hook、到站 arrival、本关可读录像成功分析 film、抵达生成器指定节点 evidence、成功离站 departure。共 35 个记录槽，不预先显示未来章节。

## 运行规则

- 录像线索在快门状态快照中进入视频提示词，成功读片后进入报告。视频生成本身仍依赖现有服务与回落机制，不能保证生成视频准确还原文字。
- 关键节点未访问不能离站。录像未显影、停电或旧关卡录像不能误推进当前章。
- 剧情广播每条至少间隔十秒，警报期间暂停投放。换章取消过期行动提示，但证据记录保留。
- 到站叙事使用现有三次敲击音效；Three.js 舱内七枚指示灯随证据进度变化，怪物不在舱内建模现身。
- J 打开只读记录与当前行动。警报阅读不暂停危险，界面提示玩家先应对。
- 第七章具备离站条件后在无线电台按 7/8/9 选择转发、封断或离线存档；选择后再离站。离线存档需至少四章读片记录。结局描述立即由已选结果提供，不等待通关后队列播放。
- 记录属于当前 PodRun；未新增完整主航线跨刷新存档系统。

## 验证与限制

- 章节内容与测试由子 Agent 编写，另一独立 Agent 检查连贯性与触发。不是盲测，不宣称 AAA 或奖项水准。
- `tools/campaign.test.ts` 使用受控状态夹具检查七章转场、三个结局和错误路径，明确不是完整驾驶通关。
- 最终 18 项剧情测试通过；独立复查的四个阻断问题已关闭：结局未选时不损失台面物资、日志不提前揭示答案、旧转场不能绕过条件、结局选择保留接听。旧录像现在回填来源章节，不错误计入当前章节。
- 主入口浏览器回归检查 J 日志及原有第一人称输入；录像与怪物 21 项原有测试通过。
- 旧 `npm run pod` 仍报告 0/12 通关：脚本依赖旧实时镜头识别等行为，不可把它的进程退出码 0 当成七关通关成功。完整连续通关仍需进一步验证。
