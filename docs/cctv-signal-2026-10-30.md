# 录像监控信号处理 · 2026-10-30

2026-10-30 监控录像风格修订（IMPLEMENTED 播放接线 / GAP 全部剧情证据验收）：用户要求参考《观测者号》的家用CCTV信号质感。普通与放大录像共用 `src/pod/view/cctv-signal.ts`，内部上限960×540、保留原色、轻度色度横向拖边/柔化/暗部噪声/高光扩散/短暂局部水平失步及弱残影；替代录像播放旧208像素宽四色映射与14条粗横带。此要求覆盖旧录像强制丢弃原色的美术约束，不改变舷窗外景、声纳机制及生成请求。等比完整显示画面，不裁切取证边缘；字幕在效果后绘制。暂停冻结效果，换片、倒退或大幅跳转清除历史；WebGL不可用时保留原片播放。实际浏览器已验证本地视频正常出图、暂停稳定和换片无残影，未证明每条剧情证据都已达到本条可读性阈值。没有提交视频生成；旧缓存继续使用。

## 接入与边界

- `footage.ts` 的普通、放大和 `drawFootageFrame` 共用GPU信号层。截图备份和GM文字调试片保留原用途。
- 保留原始视频与音轨，播放时处理画面；无读回像素的逐帧CPU调色。单个共享WebGL上下文与两张纹理，按片源比例缩放。
- 颜色拖边主要影响色度；噪声在暗处更明显。平时稳定，少量局部横带短暂偏移，不做整屏闪黑。
- 暂停时不累计残影；切换源、倒退及超过0.25秒跳转清空历史。
- 字幕、操作按钮与剧情判定不进入信号滤镜，不因此新增、丢失或改变证据。
- `degrade.ts` 与 `tools/footage-probe.ts` 是旧四色探针，已不代表当前录像显示。

## 验证

`npm run typecheck`；`node tools/cctv-signal-check.mjs` 使用本地旧视频并拦截API。实际WebGL编译无错误；暂停重复绘制一致；切到全黑片源最大通道值6（仅噪声，无上一片残影）；静态与4秒动态对照见 `qa/cctv-signal/`。结果中的meanMs只测浏览器提交时间，不代表GPU总耗时或游戏帧率。尚未逐卷检查全部剧情关键证据、所有显卡和低端设备表现。
