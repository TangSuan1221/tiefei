# 舱外猎手

怪物不进入实时取景、探照灯或三维房间；只有回收录像能够呈现其形态。声音与字幕同时传递攻击预警。雷达保留匿名回波，录像识别后才给出名称，分析台记录等级和习性。

## 七关节奏

| 剧情阶段 | 环境猎手 | 重点 | 遭遇后缓冲 |
| --- | --- | --- | --- |
| 事故教学 | 空回声 | 35 秒初始保护；录像证伪；伤害减半 | 65 秒 |
| 过于齐备 | 溺者合唱 | 搜箱、脚步、声呐引来的模仿声 | 55 秒 |
| 路径记忆 | 铁织 | 推进振动、咀嚼钢板、持续漏水 | 48 秒 |
| 不要看 | 钩灯 | 灯光诱捕、电力吞噬 | 45 秒 |
| 仍在运转 | 腐蚀巨兽 | 工业振动与腐蚀压力 | 40 秒 |
| 伴行 | 幕膜 | 舱外与舱内互相回应的敲击 | 36 秒 |
| 过于洁净 | 奔行者 | 最后的尾流追猎；略延长平静段 | 50 秒 |

原有箱子陷阱和剧情遭遇仍保留，受恢复时间保护。环境警觉以声音、实际供电灯光、推进档位加权累积；安静黑暗会降低警觉。翻箱现有声音、液压、挣脱和物品碰撞接入同一噪音入口，工位移动增加脚步噪音。

## 行为与应对

调查 → 跟踪 → 独立攻击预警 → 命中或驱离 → 恢复期。预警持续约 8–14 秒，每 2.4 秒重复敲击与该怪物的异响；制造噪音和误用物品都不能跳过这个应对窗口。正确物资或关灯、停机、断电遵循原有弱点；预先保持正确状态 3 秒也能驱离。伴行者原有复拍前等待规则保留。

等级 0 为无害动物，猎手等级 1–5 由生物危险度和关卡深度决定。克系技能分别为回声侵蚀理智、吞光损失电力、异质腐蚀增加持续漏水、越界侵入。高阶侵入怪攻击后船体低于 45% 时导致入舱死亡；其他攻击也可能令船体归零内爆或加重进水。首关不施放额外异常技能。

## 录像与离线

实时照射不会识别怪物。曝光记录回波，回收录像识别，分析台给出完整档案。没有视频服务或服务失败时使用机载五秒循环录像，怪物只在中间约两秒出现。回放绑定磁带里记录的物种，不读取当前追踪者；远端返回不含怪物的录像时同步清除该卷的识别信息。
