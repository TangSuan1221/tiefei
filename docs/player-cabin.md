# 玩家潜水艇舱

主游戏 `/` → 开始下潜使用 `CabinThree`，不是独立的关卡预览页面。

- 建模尺度：宽 2.3 m、长 4 m、高 2.1 m；脚槽净宽约 0.7 m。此为本项目设计尺寸，不声称是《铁肺》的精确尺寸。
- 前壁：摄像打捞、领航；左壁：生命支持、无线电；右壁：冲洗分析、机械臂副控。
- 当前模拟实际只有五个独立工位，旧 salvage 已合并至 camera。第六块物理屏幕是共享摄像控制回路的机械臂副控，不增设虚假独立游戏系统。
- 原有工位画布成为设备面板的实时纹理，屏幕有三维机柜、厚度、把手、托架和线束。聚焦为摄像机移动，不再覆盖全屏二维工位窗口。
- 射线检测先命中舱内实体，使用屏幕 UV 检测旧按钮。鼠标坐标先匹配后处理的呼吸、心跳与桶形畸变，干燥舱内禁用水下折射与随机 UV 撕裂；保留调色、颗粒、雾气及警报。
- 第一人称操作：点击锁定鼠标，鼠标环视，WASD 在窄脚槽移动，准星对准 1.65 m 内的屏幕按 E 操作；操作设备时释放鼠标，Esc 回到原行走位置与朝向。数字键仍为快捷操作入口。
- 采用保守的设备净空边界限制行走，不是刚体物理模拟；无跳跃、自由穿越设备或布料模拟。舱门是封死的布景。走动产生脚步声和少量噪声，平静态按步进消耗呼吸。
- 积水几何跟随进水值；停电降低主灯。外围屏幕每六帧刷新一次，操作中的面板每帧刷新。

验证：`npm run typecheck`、`npm run build`、`node tools/cabin-browser-check.mjs`。
浏览器测试包含主入口启动、五个工位快捷键、实体按钮鼠标点击、退出、从舱内点击工位及 1024×768 缩放。截图位于 `qa/cabin/`。未宣称达到 AAA 或与参考图完成盲测。

第一人称追加检查：浏览器真实 pointer lock、W 移动、D 侧移边界、鼠标环视、准星 E 进入分析台、释放锁定、退出恢复原位。WASD 已解除鼠标锁定依赖；浏览器不支持锁定时，右键拖动环视仍可用。失焦和输入框仍阻止移动。回归测试覆盖锁定及非锁定移动、右键环视和失焦安全。美术工作由独立子 Agent 补充布景，另一 Agent 对照参考图检查；不是盲测，仍不能据此声称达到 AAA。
