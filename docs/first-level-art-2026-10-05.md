# 第一关视觉制作 · 2026-10-05

运行入口：`main-authored`，`/` → `PodRun` → `HarborRescueSite` / `PodExpedition`。本轮修改美术与空间布局，既有剧情、任务、声纳规则、摄影时序和人物路线保持原实现。第二阶段按用户指出的布局差距同步修改实体几何及其碰撞，不再声称全部碰撞保持原样。

## IMPLEMENTED

- 通过已开启的 Blender MCP（本机 9876）制作压力检修模块，包含倒角蒙皮、分层圆形法兰、32 组螺栓、密封圈、转轮、管道接头、压力表及笼罩灯。六个材质网格、34,032 顶点，导出 `public/assets/deepsea/rescue-pressure-service.glb`，正式首关异步加载并复用。
- 救援港增加三座圆柱压力设施、环形检修护栏、支撑、货仓拼缝、压筋与紧固件。第一阶段装饰保留原碰撞；第二阶段新增筒桩、圆台、悬桥与隔离索按实际实体注册对应碰撞，细节见下。
- 首关漆面、钢材、地板增加低对比腐蚀和湿干粗糙度变化，降低大斑块及规则地板凸点；大型柱体按物理尺寸映射纹理。救援场景接入与主港同一材质工厂。
- 首关采用冷青侧光、低位暖灯、深度约束的散射与受限泛光。灯具模型与新增主要灯位对应。其他关卡保留原水体分支。
- 排除一条原有零长度电缆生成的非法法线，使救援视觉层可正常导出并回到 Blender 编辑。未改变任何可见电缆长度或交互。
- 提供独立压力模块 `.blend` 和从实际游戏视觉层导出的 `assets/blender/rescue-harbor-layout.blend`。后者为可编辑美术层，不能当作完整关卡执行逻辑；原游戏碰撞、触发器及任务代码仍是运行依据。
