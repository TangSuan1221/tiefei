## 因果和时间线

事故前艾里亚斯已变化 → 莱娜批准继续观察 → 尼科请求停止，万斯退回且漏接第二次联系 → 尼科分区封闭、录警告，最后关门后发求救并死亡 → 罗温抵达救下艾里亚斯 → 两人分路到第三层会合 → 袖口引起怀疑 → 莱娜的旧记录和当前录像相互核实 → 底站旧片交代尼科最后行动 → 依合作、抵达、报告状态进入相应结尾。

选择组合：上层隔离/本层隔离决定跟随者可达范围；下层门曾开启决定第四章水位，只有上层污染已放出才出现组织；复关不撤销先前流出。广播开关影响第三层定位与对白，均不删除尼科记录。私人看片不授予艾里亚斯知识；当面质问分支改变下一章对白。报告过后不提供无异常接收结尾；终止合作不提供带艾里亚斯同行结尾。

世界解释保持限度：井壁多个位置对实验产生反应是莱娜的观测证词，不证明整个海底是某个具名神明。正文不通过全知旁白宣布深海本体或岸上毁灭。
