# 连续潜艇驾驶

摄像台/领航台：按住空格推进，N 反推，J/L 转舵，I/K 纵倾，Shift 制动。领航台也支持按住 4；摄像台驾驶排和领航台推进按钮支持鼠标按住。松开后水阻逐步减速，转向角速度也逐步衰减。WASD 在离开工位后仍控制舱内步行。

采用可调的加速度、线性/二次阻力与角速度阻尼，并非完整流体动力学模拟。站内按米级速度连续推进；航渡沿用抽象航段距离，以十倍距离比例连续推进，不声称两种场景采用同一物理尺度。

沿用现有碰撞、机关、跨房间与到站逻辑；连续帧不会反复刷出“前进一步”日志。碰撞后短时停止，失焦、输入界面、拍摄锁定、停电或离开驾驶工位会安全停船。仍保留旧模拟层脉冲 API 供兼容脚本使用，玩家主要驾驶入口改用按住输入。

验证：`tools/pilot.test.ts` 检查加速、滑行、制动、倒航、30/60Hz 位移一致性、转向阻尼、真实 PodRun 前进和到站。`tools/cabin-window-check.mjs` 验证浏览器按住空格、松开滑行、左舵不打开日志、Shift 制动与观察窗缩放。
