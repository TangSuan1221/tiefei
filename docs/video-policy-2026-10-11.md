# 视频时长、计费筛选与结果预生成（2026-10-11）

入口：主游戏 /，当前首关港区与第二关生活区。用户本轮四项要求覆盖此前固定5秒生成规则。

## IMPLEMENTED

- 非剧情视频请求5秒；按快门时查询真实生物位置，艇体中心30米内无怪物则不调用生成接口，只保留真实本地感光录像。30米是本轮可调常量 VIDEO_MONSTER_RADIUS，不来自声纳推测。剧情结果录像不受怪物距离限制。
- 剧情视频请求10秒。主体可见且对应当前剧情摄影目标才分类为剧情，单独看怪物属于普通观察。首关角色/诱导/隔离/撤离与第二关可见任务目标由关卡提供语义。
- 对已经完成物理结果、只等待玩家取片的隔离/撤离/会合结果，在当前取景稳定2秒后后台预生成。未确定的袭击、尚可撤回的出发、仍依赖玩家操作的后果不预测。每0.5秒检查一次；同一确定分支只自动提交一次，同一run同时只预生成一条。预生成不创建证据、不推进任务、不告知NPC。
- 缓存绑定世界状态、认知/关系、角色、怪物、艇位、镜头、灯光。拍摄命中缓存直接交付；任务正在生成时等待同一Promise，不重复计费。状态/镜头变化不复用旧片。成功生成不再额外等待固定12秒本地显影；实际5秒曝光流程保留。
- 提示词槽位：DURATION_SECONDS / LOCATION / HUMAN_SUBJECTS / MONSTER_SUBJECTS / CURRENT_RESULT。关卡真实光学可见主体取代旧随机遭遇资料。明确锁定首帧外形、数量、衣着、姿态、遮挡；禁止把港区生物换成可爱鲨鱼等物种。看不见的主体不凭附近距离加入画面。
- 2026-10-12用户修订：5秒/10秒只约束提交请求以控制成本；返回文件不做精确片长匹配，正常可解码视频直接接收，包括5.14秒、5.184秒。仅拒绝非有限或非正的无效媒体时长，不因片长差异触发重生成。背景缓存与正常拍摄使用同一计费入口和去重逻辑。

IMPLEMENTED：tools/video-policy-check.ts验证30米边界、5/10秒策略、槽位、未定结果不预生成、相机/状态缓存变化及分支去重。tools/video-policy-browser-check.mjs拦截全部生成请求、模拟解码，验证空场景零POST、10/5秒请求、后台与拍摄合并、缓存命中、上游时长错误拒收。模拟媒体不冒充实际模型成片。真实快门分发集成检查、原有首关因果分支/第二关逻辑回归与正式构建均通过；构建仍有原有大包体提示。

GAP：真实10秒请求被自动审批拒绝，尚未向外部发送本地图片或产生该次测试费用；需用户明确批准后验证Forgeax转发层实际10秒出片与视觉效果。槽位降低物种替换概率，不宣称提示词能保证模型永不画错。

GAP：预生成覆盖当前关卡可确定的结果片；第三至五关未制作，没有虚构全章后台生成。玩家快速触发、改变机位或外部服务较慢时仍可能等待，不能保证所有录像即时可播。第二关探头的已有本地真实帧回片保持原采样，不伪称已接入云端生成。无真实距离提供者的旧入口不提交计费任务。离线/失败的本地5秒录像仍是独立证据来源，不拉伸成10秒伪生成视频。
